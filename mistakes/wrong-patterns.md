# 반복 실수 패턴 모음

틀린 문제는 여기 계속 기록. 틀릴수록 관련 유형을 반복 출제할 것.

## Lv.3 자료형 (2026-07-30)
- print() 여러 줄을 한 번에 실행되는 것처럼 착각 (순차 실행 개념 실수)

## Lv.5 if (2026-08-01)
- 콜론(`:`) 누락 에러를 `else`가 없어서 나는 에러로 착각

## Lv.6 for (2026-08-02)
- `print()`가 자동으로 줄바꿈된다는 것을 모르고 출력 결과 예측 실수

## Lv.8 함수 (2026-08-04, 교정 완료)
- `return`과 `print()`를 혼동 (함수가 값을 반환하는 것과 화면에 출력하는 것을 같다고 착각)

## Lv.9 리스트 (2026-08-05)
- 최댓값/최솟값 찾기 시 시작값(초기값) 설정을 잘못해서 틀리는 함정

## Lv.10 딕셔너리 (2026-08-10~, 진급 보류 중 — 계속 섞어서 출제할 것)

1. **키 존재 확인 방법 오류**: `dict.keys() == "keyname"`처럼 시도 (항상 `False`, 잘못된 방법)
   → 올바른 방법: `"keyname" in dict`
2. **매개변수 미사용**: 함수에서 매개변수로 받은 키 이름을 실제로 사용하지 않고, 따옴표로 감싼 고정 문자열을 키처럼 사용
   → 예: `dict["quest_name"]`(틀림, 문자열 리터럴) 대신 `dict[quest_name]`(맞음, 매개변수 변수)이어야 함
3. **괄호 혼동**: 딕셔너리 접근에 `()` 소괄호를 잘못 사용
   → `dict("key")`(틀림, 함수 호출처럼 씀) → `dict["key"]`(맞음, 대괄호로 접근)
