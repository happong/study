## 세트 1 — 범위: 1강 집합 (첫 세트, 10문제)

상태: ⏳ 출제 완료 / 채점 대기

### 🟢 초급
**1. (객관식)** 다음 중 집합이 되는 것은?
① 키가 큰 사람의 모임 ② 20의 약수의 모임 ③ 예쁜 꽃의 모임 ④ 수학을 잘하는 학생의 모임

**2. (단답형)** `A = {x | x는 10 이하의 소수}` 를 원소나열법으로 나타내시오.

**3. (O/X)** 다음이 맞으면 O, 틀리면 X
(a) `{1, 2, 2, 3}` 의 원소는 4개이다.
(b) 공집합 ∅ 는 모든 집합 A 의 부분집합이다.
(c) `{a} ∈ {a, b}`
(d) `{1, 2, 3} = {3, 1, 2}`

### 🟡 중급
**4. (객관식)** 전체집합 U = {x | x는 정수} 일 때, 다음 중 공집합은?
① `{x | x² = 4}` ② `{x | 2x − 5 = 0}` ③ `{x | |x| ≤ 0}` ④ `{x | x + 3 = 3}`

**5. (단답형)** U = {1, 2, 3, 4, 5, 6, 7, 8}, A = {1, 2, 3, 4}, B = {3, 4, 5, 6} 일 때 다음을 원소나열법으로 쓰시오.
(1) `A ∪ B` (2) `A ∩ B` (3) `Aᶜ` (4) `B − A` (5) `(A ∪ B)ᶜ`

**6. (단답 + 서술)** 5번의 집합으로 `Aᶜ ∩ Bᶜ` 를 직접 구하고, 5번 (5) 의 결과와 비교하시오. 이 결과가 어떤 법칙을 보여주는지 법칙의 이름과 식을 쓰시오.

**7. (계산)** 1부터 50까지의 자연수 중 3의 배수 **또는** 5의 배수는 몇 개인가? (사용한 공식과 각 집합의 원소 개수를 함께 쓰시오)

### 🔴 고급
**8. (확률)** 1부터 30까지 적힌 카드 30장 중 한 장을 뽑을 때, 2의 배수 또는 3의 배수가 나올 확률을 구하시오. (풀이 과정 포함)

**9. (증명형)** `A − B = A ∩ Bᶜ` 임을 이용하여 다음을 증명하시오. 각 단계에서 사용한 법칙의 이름을 쓰시오.
`(A − B) ∩ (A − C) = A − (B ∪ C)`

**10. (서술형)** 실수 전체를 전체집합으로 할 때, `A = {x | x > 2}`, `B = {x | x² > 4}` 의 포함 관계를 밝히고 (`⊂`, `⊊`, `=` 중 무엇인지), 그 이유를 설명하시오.

## 세트 2 — 중간과제물 대비 연습 (범위: 2·3·5·6·7·8강, 과제와 다른 문제)

상태: ⏳ 출제 완료 / 채점 대기 · 개념 노트: `learn/중간과제대비(개념).md`
※ 과제 규정(생성형 AI 활용 답안 = 0점) 때문에 실제 과제 문제는 출제·풀이하지 않음

### 🟢 초급
**1. (O/X)**
(a) 집합의 상한이 존재하면 최댓값도 항상 존재한다.
(b) 집합 S 의 최솟값이 존재하면 그 값은 S 의 하한과 같다.
(c) `Σ aₙ` 에서 `aₙ → 0` 이면 급수는 수렴한다.
(d) `Σ aₙ` 에서 `aₙ ↛ 0` 이면 급수는 발산한다.

**2. (단답 + 설명)** `E = {n/(n+1) | n = 1, 2, 3, …}` 의 상한, 하한, 최댓값, 최솟값을 구하고, 최댓값이 있는지 없는지 이유를 쓰시오.

### 🟡 중급
**3. (단답 + 설명)** `S = {(−1)ⁿ/n | n = 1, 2, 3, …}` 의 상한, 하한, 최댓값, 최솟값을 구하시오. (처음 6개 원소를 먼저 쓰고 시작할 것)

**4. (증명)** 모든 자연수 n 에 대하여 `1² + 2² + … + n² = n(n+1)(2n+1)/6` 임을 수학적 귀납법으로 증명하시오.

**5. (계산 + 판정)** 수열 `aₙ = (4n − 1)/(2n + 3)` 에 대하여
(1) `lim aₙ` 을 구하시오. (2) `aₙ₊₁ − aₙ` 을 계산하여 증가수열인지 감소수열인지 판정하시오.

**6. (계산)** 수열 `aₙ = (kn + 1)/(2n + 3)` 이 `lim aₙ = 3` 을 만족할 때 k 를 구하고, 그 k 에 대해 이 수열이 증가수열인지 판정하시오.

**7. (계산)** 일차함수 f, g 에 대해 모든 실수 x 에서 `(f∘g)(x) = (g∘f)(x)` 가 성립하는 상수를 구하시오.
(1) `f(x) = ax + 1`, `g(x) = 2x + 3` 일 때 a
(2) `f(x) = 3x + b`, `g(x) = x + 2` 일 때 b (없으면 없는 이유를 쓰시오)

### 🔴 고급
**8. (급수 판정)** 수렴/발산을 판정하고, 사용한 판정법의 이름과 과정을 쓰시오.
(1) `Σ (n + 1)/(n³ + 2)` (2) `Σ 2ⁿ/n!` (3) `Σ (−1)ⁿ⁺¹/(2n − 1)` — 절대수렴/조건수렴까지
(4) `Σ (n² + 1)/(3n² − n)` (5) `Σ (2n/(5n + 3))ⁿ`

**9. (연속 · 중간값 정리)** `f(x) = (e^{2x} − 1)/(3x)` (x ≠ 0), `f(0) = k`
(1) f 가 x = 0 에서 연속이 되는 k 를 구하시오.
(2) (1) 의 k 에 대해 f 가 [0, 1] 에서 연속임을 설명하시오.
(3) 방정식 `f(x) = 2` 가 (0, 1) 에서 적어도 하나의 해를 가짐을 보이시오. (e ≈ 2.718)
