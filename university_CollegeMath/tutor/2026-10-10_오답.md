# 2026-10-10 개념 확인 · 오답 기록

## 개념 질문 — 상한·하한 / 최댓값·최솟값 (2강, 중간과제 대비)

과제 1번의 풀이 순서를 묻는 질문 중에 개념 오해가 확인됨 (과제 답 자체는 다루지 않음)

| 사용자 이해 | 바른 개념 | 태그 |
|---|---|---|
| 상한 = 작은 쪽(극한값 쪽), 하한 = 큰 쪽 | **상한 = 위쪽(큰 쪽) 경계, 하한 = 아래쪽(작은 쪽) 경계** | `#정의혼동` |
| 상계가 무한히 많으니 "가장 작은 상계"는 알 수 없다 | 상계는 무한히 많아도 그중 가장 작은 것(상한)은 하나로 정해짐 (예: {1,3,5} 의 상계는 5 이상의 모든 수, 상한은 5) | `#정의혼동` |
| 4단계(후보값이 집합 안에 있는지)를 이해 못 함 | 최댓값/최솟값 = 집합 **안에 실제로 있는** 상한/하한 | `#정의혼동` |
| 예제 C={1−1/n} 에 0 이 왜 있는지 (n=0 을 넣은 줄 앎) | n=1 을 넣으면 1−1/1 = 0 | `#계산실수` |

→ 조치: 비유(천장·키)와 수직선 그림으로 재설명, 세트 2의 2·3번으로 다시 확인 예정

### 추가 질문 (같은 날)
| 사용자 이해 | 바른 개념 | 태그 |
|---|---|---|
| 상한 = 가장 높은 **원소** | 상한 = 상계 중 가장 작은 **수**. 원소가 아닐 수도 있음 (원소일 때만 최댓값과 같음) | `#정의혼동` |
| 원소가 한없이 작아지며 어떤 수에 다가가면 하한은 "무한" | 하한은 항상 **하나의 수**. 원소들이 한없이 다가가는 그 수가 아래쪽 경계 후보 (무한은 수가 아님) | `#정의혼동` |
| 상계의 뜻을 모름 | 상계 = 모든 원소보다 크거나 같은 수 (여러 개) | `#정의혼동` |
| 구간 기호 `[1, 3)` 를 모름 | `[` `]` = 끝점 포함, `(` `)` = 끝점 미포함 (2강 내용, 아직 미수강) | `#선수지식` |

→ 상한·하한 개념 혼동 같은 날 2회 → **재학습 대상**으로 지정

### 재학습 진행 (같은 날)
- 후보 수를 하나씩 "시험"하는 방법으로 설명한 뒤, 사용자가 스스로 "하계 = ○ 이하의 수, 하한 = 그중 가장 큰 수" 흐름을 찾아냄 → 추론 방향 ✅
- 남은 보완점: 하계 정의를 "가장 근접하는 수"로 표현함 → 정확한 정의는 "**모든 원소보다 작거나 같은 수**" (근접 여부와 무관). "근접"은 하한을 찾을 때 쓰는 생각
- 다음 확인: 최솟값 존재 여부(4단계), 그 수보다 조금 큰 수가 하계가 아닌 이유를 답안에 쓰는 법
