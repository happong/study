# university_CollegeMath — 방송통신대 「대학수학의 이해」 튜터

이 폴더는 **방송통신대학교 [대학수학의 이해] 과목**(통계·데이터과학과 안형미 교수) 학습을 위한 개인 튜터 시스템입니다.
루트의 Python 개인 튜터(`CLAUDE.md`), `university-programming-language/`, `university_DataStructure/` 와는
**완전히 별개의** 과목/진행 상황을 관리합니다.

## 목적

- 강의 진도를 기록하고, 배운 개념을 쉽게 정리
- 이전에 배운 개념 + 새로 배운 개념을 랜덤으로 섞어 반복 학습 (객관식 · 단답형 · 서술형 · 증명)
- 오답을 누적 기록하고, 자주 틀리는 부분은 개념 재학습으로 연결
- 최종 목표: 개념을 완벽히 이해하고 스스로 문제를 푸는 수준 → **학점 만점**

## 폴더 구조

```
university_CollegeMath/
├── README.md                 # 이 파일 (설명)
├── 학습프롬프트.md             # 튜터가 항상 따라야 하는 학습 규칙 (시스템 프롬프트 역할)
├── learn/                    # 학습 완료한 강의의 개념 정리 (문제 출제 범위)
│   └── NN강_학습제목(개념).md   # 예: 01강_집합(개념).md
├── tutor/                    # 문제 세트 · 채점 · 오답 기록
│   └── YYYY-MM-DD_오답.md      # 예: 2026-10-08_오답.md
└── materials/                # 받은 강의자료(1~8강) 요약본 — 아직 안 배운 강의 포함
    ├── README.md             # 강의 목차 · 자료 목록 · 슬라이드 정오표
    └── NN강_제목(자료).md
```

- `materials/` = "교재 요약 창고". 진도와 무관하게 받은 자료를 정리해 둔 곳.
- `learn/` = "내가 실제로 배운 것". 사용자가 "N강 배웠어"라고 알려주면 `materials/`의 해당 자료를 바탕으로
  쉬운 설명·비유·예제를 더해 `learn/`에 개념 정리를 만든다. **문제는 `learn/`에 있는 강의 범위에서만 출제.**

## 현재 진도

| 항목 | 상태 |
|---|---|
| 학습 완료 강의 | 1강 (집합) |
| 받은 자료 | 1~8강 PDF, 3·4강 파이썬 실습 노트북 |
| 시작일 | 2026-10-08 |

## 사용 흐름

1. "N강 배웠어" → `learn/NN강_...(개념).md` 생성 → 개념 설명 → 이전 강의 + 새 강의 섞어서 문제 출제
2. 답 제출 → 채점(계산 문제는 실제로 계산해서 검증) → `tutor/날짜_오답.md`에 기록
3. 같은 개념을 반복해서 틀리면 → 해당 `learn/` 파일로 돌아가 재학습 → 그 개념 위주 응용 문제
4. 채점이 끝날 때마다 commit & push

자세한 튜터 행동 규칙은 [`학습프롬프트.md`](./학습프롬프트.md) 참고.
