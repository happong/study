# 2강 — 수의 체계 (강의자료 요약)

> 출처: 대학수학의 이해 2강 「수의 체계」 강의자료 (제1장 집합과 수의 체계)
> 상태: 📦 자료만 정리됨 (아직 미수강 — 출제 범위 아님)

## 학습목표
1. 유리수·무리수를 포함하는 실수 체계의 구조와 기본 연산 성질 이해
2. 실수 직선 위의 구간 표현과 절댓값의 성질
3. 유계성을 바탕으로 상한·하한과 최대·최소의 차이 구분
4. 연역법, 귀류법, 수학적 귀납법으로 명제 증명

## 1. 실수 체계
- 자연수 `𝒩 = {1, 2, 3, …}` : 1을 거듭 더해 만든 양의 정수
- 정수 `𝒵 = {…, −2, −1, 0, 1, 2, …}` (독일어 Zahlen 에서 유래)
- 유리수 `𝒬 = {n/m | m ∈ 𝒵∖{0}, n ∈ 𝒵}` : 분수로 나타낼 수 있는 수 (이탈리아어 Quoziente) — 유한소수, 순환소수
- 무리수 : 순환하지 않는 무한소수 (√2, π, e …)
- 실수 `ℛ` = 유리수 ∪ 무리수, 포함관계 `ℛ ⊃ 𝒬 ⊃ 𝒵 ⊃ 𝒩`

## 2. 실수의 성질
- **가산집합**: 자연수 집합과 일대일대응이 존재 (번호를 매겨 셀 수 있는 무한집합). 유리수는 가산집합.
- **비가산집합**: 실수는 셀 수 없음 — Cantor 의 대각선 논법 (0~1 사이 실수를 다 나열했다고 가정해도, 대각선 숫자를 모두 바꾼 수 b 는 목록에 없음)
- **조밀성**: 서로 다른 두 실수 a < b 사이에는 항상 또 다른 실수 존재 (예: (a+b)/2)
- 실수와 수직선은 일대일대응
- 연산 성질: 닫힘, 교환법칙, 결합법칙 `(a+b)+c = a+(b+c)`, `(ab)c = a(bc)`, 분배법칙, 항등원(0, 1), 역원(−a, a⁻¹)
- 삼분법칙: 임의의 실수 a 는 `a > 0`, `a = 0`, `a < 0` 중 정확히 하나
- 대소 성질: 전이성, 가감법칙, 양수 곱은 부등호 유지, **음수 곱은 부등호 반대**
- 절댓값: 원점과의 거리. `|a| = a (a ≥ 0)`, `|a| = −a (a < 0)`, `|a| ≥ 0`, `|a| = |−a|`, `|ab| = |a||b|`, `|a/b| = |a|/|b|`
- 예제 1.18: `|a+1| + |a−2|`
  - a < −1 → `−2a + 1`
  - −1 ≤ a < 2 → `3`
  - a ≥ 2 → `2a − 1`

## 3. 구간, 유계, 상한과 하한
- 열린구간 `(a, b)`, 닫힌구간 `[a, b]`, 반열린구간 `(a, b]`, `[a, b)`, 무한구간 `(a, ∞)`, `(−∞, ∞) = ℛ` 등
- **상계**: 구간 내 모든 수 이상인 수 M / **상한(sup)**: 상계 중 가장 작은 것 (최소상계)
- **하계**: 구간 내 모든 수 이하인 수 m / **하한(inf)**: 하계 중 가장 큰 것 (최대하계)
- 상계·하계는 여러 개일 수 있지만 상한·하한은 **유일**
- 위로 유계 = 상계 존재 / 아래로 유계 = 하계 존재
- 최댓값·최솟값: 구간 **안에** 실제로 있는 가장 큰/작은 값 (끝점이 포함되어야 존재, 이때 상한/하한과 같음)
- 예제 1.19

| 구간 | 상계 | 상한 | 최댓값 | 하계 | 하한 | 최솟값 |
|---|---|---|---|---|---|---|
| `[5, ∞)` | 없음 | 없음 | 없음 | 5 이하 모든 실수 | 5 | 5 |
| `[−1, 1]` | 1 이상 모든 실수 | 1 | 1 | −1 이하 모든 실수 | −1 | −1 |
| `(0, 2]` | 2 이상 모든 실수 | 2 | 2 | 0 이하 모든 실수 | 0 | **없음** |

## 4. 수학적 논리 전개
- **정의**: 용어의 뜻을 정하는 약속 (증명 불필요) / **정리**: 증명을 통해 참임이 밝혀진 명제
- **명제**: 참/거짓 판별 가능한 문장 `P → Q`
- **대우**: `~Q → ~P` (원래 명제와 논리적으로 동치)
- `P ⇒ Q` 가 참이면 P 는 Q 의 **충분조건**, Q 는 P 의 **필요조건**. 양방향이면 **필요충분조건** (동치)
- **연역법(직접증명)** — 예제 1.20: n = 2k 이면 n² = 4k² = 2(2k²) → 짝수
- **귀류법(간접증명)** — 예제 1.21: √2 = a/b (a, b 서로소) 라고 가정 → 2b² = a² → a 짝수 → a = 2k → b² = 2k² → b 짝수 → 서로소 모순
- **수학적 귀납법** — 예제 1.22: `1 + 2 + … + n = n(n+1)/2`
  1. n = 1 일 때 성립 확인
  2. n = k 일 때 성립한다고 가정 → n = k+1 일 때 `k(k+1)/2 + (k+1) = (k+1)(k+2)/2` 성립
