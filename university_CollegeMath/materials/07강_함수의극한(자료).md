## 학습목표
1. 함수 극한의 기하학적 의미와 ε-δ 정의
2. 수열의 극한과 함수의 극한 비교
3. 부정형 극한을 식 변형으로 계산
4. 삼각함수 극한 공식 도출과 응용

## 1. 함수 극한의 정의
- `lim_{x→a} f(x) = b` : x 가 a 와 **같지 않으면서** a 로 접근할 때 f(x) 가 b 에 가까워짐
- 극한값 ≠ 함숫값 (예: x → 4 일 때 극한 2 이지만 f(4) = 1 인 그래프)
- `|x|/x` : x → 0⁺ 에서 1, x → 0⁻ 에서 −1 / `1/x` : 0⁺ 에서 +∞, 0⁻ 에서 −∞
- **좌극한** `lim_{x→a⁻}`, **우극한** `lim_{x→a⁺}`
- ⭐ 극한 존재 ⇔ 좌극한과 우극한이 모두 존재하고 같음
  - 예제 4.1: `f(x) = −1 (x < 0), 1 (x ≥ 0)` → 좌극한 −1, 우극한 1 → 극한 없음
- **ε-δ 정의**: 임의의 ε > 0 에 대하여 `0 < |x − a| < δ` 인 모든 x 에서 `|f(x) − b| < ε` 을 만족하는 δ > 0 가 존재

| | 수열의 극한 | 함수의 극한 |
|---|---|---|
| 출발 | 임의의 ε > 0 | 임의의 ε > 0 |
| 존재해야 하는 것 | 자연수 N | 양수 δ |
| 조건 | n > N 이면 `|aₙ − α| < ε` | `0 < |x − a| < δ` 이면 `|f(x) − b| < ε` |

- 무한대에서의 극한 `lim_{x→±∞} f(x) = b` (수평점근선) / 무한대로 발산 `lim f(x) = ±∞`

## 2. 극한의 성질
- `lim c = c`, `lim xⁿ = aⁿ`, `lim (cf + b) = c·lim f + b`, 합·차·곱·몫 (몫은 분모 극한 ≠ 0) — x → ±∞ 에서도 성립
- **부정형**: `∞/∞`, `∞ − ∞`, `0/0`, `0·∞` → 인수분해 · 유리화 · 약분 · 최고차항으로 나누기
- 예제 4.3
  1. `lim_{x→2} x²/(x + 2) = 4/4 = 1` (그냥 대입)
  2. `lim_{x→1} (x³ − 1)/(x − 1) = lim (x² + x + 1) = 3` (0/0 → 인수분해)
  3. `lim_{x→∞} (√(x² + x) − x) = 1/2` (∞ − ∞ → 켤레식으로 유리화)
  4. `lim_{x→∞} √(4x² + x)/(x + 2) = 2` (∞/∞ → 분모 최고차항 x 로 나누기)

## 3. 삼각함수의 극한
- ⭐ `lim_{x→0} sin x / x = 1`, `lim_{x→0} tan x / x = 1`
- 증명: 단위원에서 넓이 비교 `△OBC ≤ 부채꼴 OBC ≤ △OBA` → `sin x ≤ x ≤ tan x` (0 < x < π/2)
  → `cos x ≤ sin x / x ≤ 1` → 조임정리로 1, 좌극한은 `sin(−x) = −sin x` 로 동일
- 예제 4.4
  1. `lim_{x→0} sin x / sin 2x = 1/2`
  2. `lim_{x→0} (1 − cos x)/x² = 1/2` (분자·분모에 `1 + cos x` 곱하기 → `sin²x/(x²(1 + cos x))`)
