## 1. 연속의 정의
- 직관: 그래프를 **한붓그리기**로 그릴 수 있음
- ⭐ x = a 에서 연속 ⇔ 세 조건 모두 만족
  1. `f(a)` 가 정의됨 — 반례: `|x|/x` 는 x = 0 에서 정의 X
  2. `lim_{x→a} f(x)` 존재 (좌극한 = 우극한) — 반례: `−1 (x<0), 1 (x≥0)`
  3. `lim_{x→a} f(x) = f(a)` — 반례: `(x² − 4)/(x − 2) (x ≠ 2), 0 (x = 2)` → 극한 4 ≠ 0
- 예제: `f(x) = (x² − 4)/(x − 2) (x ≠ 2), k (x = 2)` 가 연속이 되는 k → `lim (x + 2) = 4` ∴ **k = 4**
- 구간 I 의 모든 점에서 연속 → 구간 I 에서 연속 / 하나라도 연속이 아니면 불연속
- **ε-δ 정의**: 임의의 ε > 0 에 대하여 `|x − a| < δ` 인 모든 x 에서 `|f(x) − f(a)| < ε` 인 δ > 0 존재
  (극한 정의의 b 자리에 f(a) 가 들어간 것 = 함숫값 존재 + 극한 존재 + 둘이 같음)

## 2. 연속함수의 성질
- f, g 가 구간 I 에서 연속 → `cf`, `f ± g`, `f·g`, `f/g (g ≠ 0)` 연속
- 합성 `f∘g` 연속 (g 의 치역 ⊆ f 의 정의역일 때)
- 예제 4.5: `f(x) = cos(x³ − 5)` = `h∘g` (g = x³ − 5, h = cos) → 실수 전체에서 연속
- ⭐ **최대최소 정리**: 닫힌구간 [a, b] 에서 연속이면 반드시 최댓값과 최솟값을 가짐
  - 조건이 깨지면(열린구간, 불연속점) 최대/최소가 없을 수 있음
  - 예제 4.6: `[0, 3]` 에서 `x² − 4x + 2 = (x − 2)² − 2` → 최솟값 −2 (x = 2), f(0) = 2, f(3) = −1 → 최댓값 2 (x = 0)
- ⭐ **중간값 정리**: [a, b] 에서 연속이고 `f(a) ≠ f(b)` 이면, f(a) 와 f(b) 사이의 임의의 k 에 대해 `f(c) = k` 인 c 가 (a, b) 안에 적어도 하나 존재
  - 활용: 부호가 바뀌는 구간마다 실근이 적어도 1개
  - 예제 4.7: `f(−1) = 1/2, f(0) = −1/3, f(1) = −1, f(2) = 5/2, f(3) = 2` 일 때 `f(x) − x = 0` 의 실근
    → `g(x) = f(x) − x` : `g(−1) = 3/2, g(0) = −1/3, g(1) = −2, g(2) = 1/2, g(3) = −1`
    → 부호 변화 3번 ((−1,0), (1,2), (2,3)) → **적어도 3개**
