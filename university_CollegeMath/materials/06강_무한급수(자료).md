# 6강 — 무한급수 (강의자료 요약)

> 출처: 대학수학의 이해 6강 「무한급수」 강의자료 (제3장 수열의 극한과 무한급수)
> 상태: 📦 자료만 정리됨 (아직 미수강 — 출제 범위 아님)

## 학습목표
1. 무한급수와 부분합의 관계, 수렴·발산의 정의
2. 등비급수의 수렴 조건과 합
3. 비교 · p-급수 · 비율판정법
4. 교대급수의 수렴 요건, 절대수렴과 조건수렴

## 1. 무한급수의 수렴
- 무한급수 `Σ_{k=1}^{∞} aₖ = lim_{n→∞} Σ_{k=1}^{n} aₖ`, 부분합 `Sₙ = a₁ + … + aₙ`
- 부분합 수열 {Sₙ} 이 S 로 수렴 ⇔ 급수가 S 로 수렴
- ⭐ 급수가 수렴하면 `aₙ → 0` (증명: `aₙ = Sₙ − Sₙ₋₁ → S − S = 0`)
  - **대우**: `aₙ ↛ 0` 이면 급수는 발산 (역은 성립 X — 예: Σ1/k)
- 예제 3.7
  - `Σ 1/(n(n+1))` → `1/n − 1/(n+1)` 로 분해(망원급수) → `Sₙ = 1 − 1/(n+1)` → 1 로 수렴
  - `1 + (−1) + 1 + (−1) + …` → `aₙ ↛ 0` 이므로 발산. 무한합에서는 괄호 위치·순서를 바꾸면 결과가 달라질 수 있음 (결합·교환법칙 일반적으로 성립 X)
- 예제 3.8: `Σ k²/(k² + 1)` → 일반항 → 1 ≠ 0 → 발산
- 수렴하는 두 급수: `Σ(aₖ ± bₖ) = Sα ± Sβ`, `Σ caₖ = cSα`

## 2. 무한등비급수
- `aₙ = arⁿ⁻¹`, `Sₙ = a(1 − rⁿ)/(1 − r)` (r ≠ 1)
- `|r| < 1` → `a/(1 − r)` 로 수렴 / `|r| ≥ 1` → 발산 (a ≠ 0)
- 예제 3.10: `Σ[(1/3)^(k−1) + 4·(1/5)^k] = 3/2 + 1 = 5/2`

## 3. 수렴 판정법
- **양항급수** (aₙ ≥ 0): 수렴 ⇔ 부분합이 유계 (부분합이 단조증가 → 단조수렴정리)
- **비교판정법** (`0 ≤ aₙ ≤ bₙ`): Σbₖ 수렴 ⇒ Σaₖ 수렴 / Σaₖ 발산 ⇒ Σbₖ 발산
  - 예제 3.11: `Σ 1/k²` — 항을 묶어 `< 1 + 1/2 + 1/4 + … = 2` → 수렴
  - 예제 3.12: `Σ 1/k` (조화급수) — 항을 묶어 `> 1 + 1/2 + 1/2 + …` → 발산
- **p-급수**: `Σ 1/kᵖ` 는 `p > 1` 수렴, `p ≤ 1` 발산
  - 예제 3.13: `Σ 1/√k` (p = 1/2) → 발산
- **비율판정법**: `lim aₙ₊₁/aₙ = c` 일 때 `c < 1` 수렴, `c > 1` 발산, `c = 1` 판정 불가
  - 예제 3.14: `Σ 4k/3ᵏ` → c = 1/3 < 1 → 수렴
- **교대급수 수렴정리**: 단조감소하는 양항수열 aₙ 에 대해 `Σ(−1)^(k−1)aₖ` 수렴 ⇔ `aₙ → 0`
  - 예제 3.15: `1 − 1/2² + 1/3² − …` → 수렴
- **절대수렴**: `Σ|aₖ|` 가 수렴 → 원래 급수도 항상 수렴
- **조건수렴**: 원래 급수는 수렴하지만 절대수렴은 아님
  - 예제 3.15: 절댓값 급수 `Σ 1/k²` (p = 2) 수렴 → 절대수렴
- 판정 전략: ① `lim aₙ ≠ 0` 이면 발산 ② 특수형(등비, p-급수)? ③ 양항: 다항식/무리식 → 비교, n!·지수 → 비율 ④ 교대: 절대수렴 확인 또는 교대급수 정리
