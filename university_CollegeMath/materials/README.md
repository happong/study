## ⚠️ 슬라이드 정오표

강의자료를 정리하면서 발견한, 오타 또는 계산 오류로 보이는 부분입니다. 원본 페이지 이미지를 직접 확인했고,
수치는 Python 으로 다시 계산했습니다. (교수님 정정 공지가 있었는지는 확인할 수 없습니다 — 강의 게시판 확인 권장)

| 강 | 위치 | 슬라이드 표기 | 바른 내용 | 근거 |
|---|---|---|---|---|
| 1강 | 4. 유한집합의 원소 개수 예제 (p.38) | `n(B) = 8`, `10 + 8 − 3 = 13`, `n(A×B) = 10·8 = 80` | `n(B) = 6`, `10 + 6 − 3 = 13`, `n(A×B) = 10·6 = 60` | 20 이하 3의 배수 = {3,6,9,12,15,18} → 6개. 10+8−3 은 15이므로 식 자체도 불일치 |
| 3강 | 예제 2.3 ② (p.13) | `3x₁−1 = 3x₂−1 ⇒ x₁ = x₂` : 전사함수 / `Y = ℛ = f(X)` : 단사함수 | 앞 줄이 **단사**, 뒷 줄이 **전사** (결론 "전단사"는 맞음) | 같은 슬라이드 ① 에서는 같은 형태의 식을 단사로 판정 |
| 6강 | 절대수렴과 조건수렴 | 조건수렴(Absolute convergent) | 조건수렴(Conditionally convergent) | 영문 용어 오타로 보임 |
| 8강 | 연속 예제 (p.12) | `lim (x² − 2)/(x − 2)` | `lim (x² − 4)/(x − 2)` | 문제의 함수식은 `x² − 4`, 결과 `x + 2 → 4` 도 `x² − 4` 기준 |

## 파이썬 실습 노트북 (3·4강)
- 3강 노트북: `f(x) = x⁴ + x² + 1` 그래프 (numpy `linspace`, matplotlib `plot`)
- 4강 노트북: sin/cos/tan, `2sin(2x+π/4)`, 지수(`e^x, 2^x, (1/2)^x`), 로그(`ln x, log_{1/2} x`), 직선, 포물선, 원·타원(`meshgrid` + `contour`)
- 핵심 코드는 각 강의 자료 요약 파일에 정리
