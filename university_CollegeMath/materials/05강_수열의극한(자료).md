# 5강 — 수열의 극한 (강의자료 요약)

> 출처: 대학수학의 이해 5강 「수열의 극한」 강의자료 (제3장 수열의 극한과 무한급수)
> 상태: 📦 자료만 정리됨 (아직 미수강 — 출제 범위 아님)

## 학습목표
1. 수열의 규칙성 → 일반항
2. 수렴과 발산의 의미, 극한 기호
3. 수렴하는 수열의 성질로 극한의 사칙연산 계산
4. 조임정리, 유계인 단조수열의 성질로 극한 판정

## 1. 무한수열
- 수열 = 함수 `f: 𝒩 → ℛ`, `f(n) = aₙ`. 항(term), 번호(index)
- 유한수열 / 무한수열
- 등차수열 `aₙ = a₁ + (n − 1)d`, 등비수열 `aₙ = a₁ r^(n−1)`
- 예제 3.1: `1, 3, 5, 7, …` → `2n − 1`, `3, 6, 12, 24, …` → `3·2^(n−1)`

## 2. 수렴과 발산
- **수렴**: n 이 커질 때 aₙ 이 α 에 한없이 가까워짐 → `lim_{n→∞} aₙ = α`
- **ε-N 정의**: 임의의 ε > 0 에 대하여, `n > N` 인 모든 n 에서 `|aₙ − α| < ε` 을 만족하는 자연수 N 이 존재
- **발산**: 수렴하지 않음 — 양/음의 무한대 발산, 진동
  - 유계인 진동 `(−1)ⁿ`, 무한 진동 `(−1)ⁿ·n`
- 예제 3.2: `n/100 → ∞`, `−n/4 → −∞`, `(−1)^(n−1)(2n−1)/(2n)` → 발산(유계인 진동, ±1 근처를 오감)

## 3. 수렴 수열의 성질
- **유일성**: 극한값은 하나 (귀류법 + 삼각부등식으로 증명)
- **유계**: `|aₙ| ≤ M`. 수렴하면 유계 (역은 거짓, 반례 `(−1)ⁿ`)
- **단조수열**: `aₙ ≤ aₙ₊₁` 단조증가 / `aₙ ≥ aₙ₊₁` 단조감소 (등호 없으면 엄격한 증가/감소)
- ⭐ **단조수렴정리**: 단조이고 유계인 수열은 수렴 (단조증가면 상한으로 수렴)
- 예제 3.3: `(1 + 1/n)ⁿ` — 이항정리로 전개 → `< 3` (유계), n 이 커지면 증가 (단조) → 수렴
- **자연상수** `e = lim (1 + 1/n)ⁿ`, `ln e = 1`
  - 예제 3.4: `lim (1 + 2/n)ⁿ = e²` (2/n = 1/k 로 치환)
- 연산: `lim(aₙ ± bₙ) = α ± β`, `lim caₙ = cα`, `lim aₙ/bₙ = α/β` (β ≠ 0), `lim aₙbₙ = αβ`, `aₙ ≥ bₙ ⇒ α ≥ β`
- 예제 3.5
  - `(2n − 1)/n + √(4n² + 1)/(2n)` → `(2 − 1/n) + √(1 + 1/(4n²))` → 2 + 1 = 3
  - `√(n² + 2n) − n` → 유리화 → `2n/(√(n²+2n) + n)` → 1
  - `5ⁿ/(5ⁿ + 4ⁿ)` → `1/(1 + (4/5)ⁿ)` → 1
- ⭐ **조임정리**: `aₙ ≤ xₙ ≤ bₙ`, `lim aₙ = lim bₙ = α` ⇒ `lim xₙ = α`
  - 예제 3.6: `4n² − 1 ≤ aₙ ≤ √(16n⁴ + 3n − 1)` → `lim aₙ/(n² + 1) = 4`
