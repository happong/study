## 1. 삼각함수
- **초월함수**: 대수적 연산으로 표현할 수 없는 함수 (삼각함수, 지수·로그함수)
- **호도법**: 반지름과 같은 길이의 호가 만드는 중심각 = 1 rad → `180° = π`, `90° = π/2`, `60° = π/3`, `45° = π/4`
- 직각삼각형(빗변 c, 밑변 a, 높이 b): `sin θ = b/c`, `cos θ = a/c`, `tan θ = b/a`
- 특수각

| θ | π/6 | π/4 | π/3 |
|---|---|---|---|
| sin | 1/2 | √2/2 | √3/2 |
| cos | √3/2 | √2/2 | 1/2 |
| tan | √3/3 | 1 | √3 |

- 원(반지름 r) 위의 점 P(x, y): `sin θ = y/r`, `cos θ = x/r`, `tan θ = y/x (x ≠ 0)`
- 역수 함수: `cosec θ = r/y`, `sec θ = r/x`, `cot θ = x/y`
- `sin²θ + cos²θ = 1`
- 그래프: sin — 원점대칭(기함수), 주기 2π / cos — y축대칭(우함수), 주기 2π / tan — 기함수, 주기 π, 점근선 `x = (2n+1)π/2`
- **주기함수**: `f(x + T) = f(x)` 인 상수 T 존재. 주기 = 가장 작은 양수 T, 주파수 = 1/T
- `y = A sin(ωx + φ)` : 진폭 `|A|`, 각주파수 ω, 주기 `2π/ω`, 위상각 φ
  - 예제 2.9: `y = 2 sin(2x + π/4)` → 진폭 2, 주기 π, 위상각 π/4

## 2. 지수함수와 로그함수
- 지수법칙: `a^(x+y) = aˣaʸ`, `a^(x−y) = aˣ/aʸ`, `(aˣ)ʸ = a^(xy)`, `(ab)ˣ = aˣbˣ`, `a^(1/x) = ˣ√a`
- 지수함수 `y = aˣ (a > 0)`: 치역 = 양의 실수. `0 < a < 1` 감소, `a > 1` 증가, `a = 1` 상수함수
- 자연상수 `e = 2.71828…`, `y = eˣ = exp(x)`
- 예제 2.10: `f(x) = (eˣ − e⁻ˣ)/(eˣ + e⁻ˣ)`, `f(a) = 1/4`, `f(b) = 1/2`
  - `f(x) = (e²ˣ − 1)/(e²ˣ + 1)` 로 변형 → `e²ᵃ = 5/3`, `e²ᵇ = 3`, `f(a+b) = (5 − 1)/(5 + 1) = 2/3`
- **로그함수** = 지수함수의 역함수 `y = logₐ x` : 정의역 x > 0, 치역 ℛ. 자연로그 `ln x = logₑ x`, 상용로그(밑 10)
- `logₐ aˣ = x`, `a^(logₐ x) = x`
- 성질: `logₐx + logₐy = logₐ(xy)`, `logₐx − logₐy = logₐ(x/y)`, `logₐ bˣ = x logₐ b`, `logₐ x = log_b x / log_b a` (밑변환)
- 예제 2.12: `y = ln(x + √(x² − 1))` (x ≥ 1) 의 역함수 → `y = (eˣ + e⁻ˣ)/2` (x ≥ 0)

## 3. 방정식의 그래프
- 방정식 `F(x, y) = 0` 을 만족하는 순서쌍 전체 / 함수 `y = f(x)` ⇔ `y − f(x) = 0` (함수는 방정식의 부분집합)
- 직선 `ax + by + c = 0` → `y = −(a/b)x − c/b` (기울기, y절편)
- 기울기 `β = Δy/Δx = (y₂ − y₁)/(x₂ − x₁)`, 점 (x₁, y₁) 지나는 직선 `y − y₁ = β(x − x₁)`
  - 예제 2.13: (2, 1), (4, 5) → β = 2 → `y = 2x − 3`
- 원: 중심 (x₁, y₁), 반지름 r → `(x − x₁)² + (y − y₁)² = r²`
  - 예제 2.14: 중심 (1, 2), 반지름 5 → `(x − 1)² + (y − 2)² = 25`
- 타원: 초점 (±c, 0), 거리 합 2a → `x²/a² + y²/b² = 1`, `b² = a² − c²`
  - 예제: 초점 (±2, 0), 거리 합 6 → a = 3, c = 2, b² = 5 → `x²/9 + y²/5 = 1`

## 4. 파이썬 실습 (4강 노트북 요약)
```python
x = np.linspace(-2*np.pi, 2*np.pi, 1000)
plt.plot(x, np.sin(x)); plt.plot(x, np.cos(x))      # 삼각함수
y3 = np.tan(x); y3[np.abs(y3) > 100] = np.nan       # tan 점근선 근처 끊기
y = 2*np.sin(2*x + np.pi/4)                          # 진폭·주기·위상 변형
np.exp(x), 2**x, (1/2)**x                            # 지수함수
np.log(x), np.log(x)/np.log(1/2)                     # 자연로그, 밑변환으로 log_{1/2}
X, Y = np.meshgrid(x, y)                             # 원/타원: 격자 만들고
plt.contour(X, Y, (X-1)**2 + (Y-2)**2 - 25, levels=[0])  # F(x,y)=0 등고선
plt.gca().set_aspect('equal')                        # 축 비율 동일
```
