## 1. 함수
- **함수** `f: X → Y` : X 의 각 원소에 Y 의 원소가 **오직 하나씩** 대응
  - 정의역(Domain) X, 공역(Codomain) Y, 정의역·공역이 모두 실수 → 실수 함수
- 함숫값 `y = f(x)`, **치역(Range)** `f(X) = {f(x) ∈ Y | x ∈ X} ⊆ Y` (공역의 부분집합)
- 함수 성립 조건: **존재성** (정의역의 모든 원소가 대응) + **유일성** (각 원소에 하나만 대응)
- 함수의 그래프: 순서쌍 `{(x, f(x)) | x ∈ X}` 전체
  - 예제 2.2: `g: ℛ → ℛ, g(x) = x² + 1` 의 치역 `{y ∈ ℛ | y ≥ 1}`

## 2. 전사 · 단사 · 전단사 · 역함수
- **전사(surjective)**: 공역 = 치역 (`Y = f(X)`)
- **단사(injective)**: `x₁ ≠ x₂ ⇒ f(x₁) ≠ f(x₂)` (대우: `f(x₁) = f(x₂) ⇒ x₁ = x₂`)
- **전단사(bijective)**: 전사 + 단사 = 일대일대응
- 예제 2.3
  - `f: 𝒵 → 𝒵, f(x) = −2x` : 단사 O, 치역 = 짝수 ≠ 𝒵 → 전사 X
  - `g: ℛ → ℛ, g(x) = 3x − 1` : `3x₁−1 = 3x₂−1 ⇒ x₁ = x₂` → **단사**, 치역 = ℛ → **전사** ∴ 전단사
    (⚠️ 슬라이드에는 두 줄의 "전사/단사" 표기가 서로 바뀌어 있음 — 정오표 참고)
- 수평선 검사: 단사 = 모든 수평선과 교점 ≤ 1개 / 전사 = 모든 수평선과 교점 존재 / 전단사 = 정확히 1개
- **역함수** `f⁻¹: Y → X`, `f⁻¹(y) = x ⇔ y = f(x)` — **전단사일 때만** 존재
  - 예제 2.4: `g(x) = 3x − 1` → `g⁻¹(x) = (1/3)x + 1/3`

## 3. 함수의 연산 · 합성함수
- `(f ± g)(x) = f(x) ± g(x)`, `(f·g)(x) = f(x)g(x)`, `(f/g)(x) = f(x)/g(x)` (g(x) ≠ 0), `(αf)(x) = αf(x)`
- **합성함수** `(g ∘ f)(x) = g(f(x))` — 성립 조건: **f 의 치역 ⊆ g 의 정의역**
- 예제 2.6: `f(x) = x + 1`, `g(x) = √x (x ≥ 0)`
  - g∘f 의 가장 큰 정의역: `x + 1 ≥ 0 ⇔ x ≥ −1` → `(g∘f)(x) = √(x+1)`
  - `(f∘g)(x) = √x + 1` (x ≥ 0)
- 성질: 교환법칙 **X** (`g∘f ≠ f∘g`), 결합법칙 **O** (`(h∘g)∘f = h∘(g∘f)`)
- `f ∘ f⁻¹ = f⁻¹ ∘ f = I` (항등함수), f 와 f⁻¹ 의 그래프는 `y = x` 에 대해 대칭

## 4. 함수의 형태와 종류
- **우함수(even)**: `f(−x) = f(x)` → y축 대칭 / **기함수(odd)**: `f(−x) = −f(x)` → 원점 대칭
- 예제 2.7: `x⁴ + x² + 1` 우함수, `x³ + 3x` 기함수, `x² + 3x` 둘 다 아님
- 상수함수 `f(x) = C`, 항등함수 `f(x) = x`
- **대수적 함수**: 상수·항등함수에 사칙연산, 거듭제곱, 거듭제곱근을 유한 번 적용
  - 다항함수 `a₀xⁿ + … + aₙ`, 유리함수 `p(x)/q(x)`, 무리함수 (근호 포함)
  - 예제 2.8: `3x³ − 2x² + 7` 다항, `2x²/(x−3)` 유리, `√(x+2)` 무리

## 5. 부록 — 파이썬 그래프 (Google Colab)
그래프 작성 절차: ① 패키지 불러오기 ② x 범위 설정 ③ 함숫값 계산 ④ 세부사항 조정 후 출력
```python
import numpy as np
import matplotlib.pyplot as plt
x = np.linspace(-2, 2, 100)   # (시작, 끝, 점의 개수)
y = x**4 + x**2 + 1           # 거듭제곱은 **
plt.plot(x, y)
plt.show()
```
