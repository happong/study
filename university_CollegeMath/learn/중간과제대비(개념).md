## 개념 1. 집합의 상한·하한 vs 최댓값·최솟값 (2강)

🏠 **비유**: 집합 = 방 안의 사람들. **상계** = 방 안 모든 사람보다 키가 크거나 같은 "천장 높이 후보"들.
**상한(sup)** = 그중 **가장 낮은 천장**. **최댓값** = 실제로 **방 안에 있는** 가장 큰 사람.

- 상계 M: 모든 x ∈ S 에 대해 `x ≤ M`
- 상한 `sup S` = 상계 중 가장 작은 것 (최소상계)
- 하계 m: 모든 x ∈ S 에 대해 `m ≤ x` / 하한 `inf S` = 하계 중 가장 큰 것 (최대하계)
- ⭐ **최댓값 = 집합 안에 들어 있는 상한** / 최솟값 = 집합 안에 들어 있는 하한
  - 상한이 집합에 속하면 → 최댓값 = 상한
  - 상한이 집합에 속하지 않으면 → **최댓값 없음** (상한은 있음)
- 2강 예제 1.19: `(0, 2]` → 하한 0, 최솟값 **없음** (0 ∉ (0, 2])

### 원소가 수열로 주어진 집합 다루는 법
1. 처음 몇 개 원소를 직접 써본다 (n = 1, 2, 3, 4 …)
2. 커지는지/작아지는지(단조성) 확인
3. n → ∞ 일 때 어디로 가는지(극한) 확인 — 그 값이 상한 또는 하한 후보
4. 후보값이 **집합에 실제로 속하는지** 확인 → 최댓값/최솟값 여부 결정
5. "상한이 정말 그 값인가?" 설명: ① 그 값이 상계(하계)임 ② 그보다 조금이라도 작은(큰) 수는 상계(하계)가 아님 (극한으로 한없이 가까워지므로)

📌 **풀이 예시 (과제와 다른 집합)**: `C = {1 − 1/n | n = 1, 2, 3, …}`
- 원소: 0, 1/2, 2/3, 3/4, … → 증가, n → ∞ 이면 1 − 1/n → 1
- 모든 원소 < 1 이므로 1 은 상계. 1 보다 작은 수 1 − ε 은 n 이 충분히 크면 1 − 1/n 이 넘어서므로 상계가 아님 → `sup C = 1`
- 1 − 1/n = 1 이 되는 자연수 n 없음 → 1 ∉ C → **최댓값 없음**
- 첫 원소 0 이 가장 작고 0 ∈ C → `inf C = 0`, **최솟값 = 0**
- `D = C ∪ {1}` 이면 1 ∈ D 이므로 sup D = 1 이 **최댓값**이 됨
- → 같은 상한이라도 "집합에 들어 있느냐"에 따라 최댓값 존재 여부가 달라짐

## 개념 2. 수학적 귀납법 (2강)

🧱 **비유**: 도미노. ① 첫 번째가 넘어진다 ② k번째가 넘어지면 k+1번째도 넘어진다 → 전부 넘어진다.

**답안 틀 (그대로 따라 쓰기)**
1. **(기초 단계)** n = 1 일 때 양변을 각각 계산 → 같음을 보임
2. **(귀납 가정)** n = k 일 때 성립한다고 가정 — 식을 **그대로 써 둔다**
3. **(귀납 단계)** n = k + 1 일 때 좌변을 변형 → **가정한 식이 나오도록 쪼갠다** → 가정을 대입 → 우변 모양으로 정리
4. **(결론)** 수학적 귀납법에 의해 모든 자연수 n 에 대해 성립

⭐ 핵심 기술: "k+1 번째 = k 번째 + 새로 추가된 한 항" 으로 쪼개기
- 합 `Sₖ₊₁ = Sₖ + (k+1번째 항)`
- 다항식 `1 + x + … + xᵏ⁺¹ = (1 + x + … + xᵏ) + xᵏ⁺¹` 처럼, **변수 x 가 들어 있어도 n 에 대한 귀납법**은 똑같이 적용

📌 **풀이 예시 (과제와 다른 식)**: `1/(1·2) + 1/(2·3) + … + 1/(n(n+1)) = n/(n+1)`
- n = 1: 좌변 1/2, 우변 1/2 ✔
- n = k 가정: `1/(1·2) + … + 1/(k(k+1)) = k/(k+1)`
- n = k+1: 좌변 = `k/(k+1) + 1/((k+1)(k+2))` = `(k(k+2) + 1)/((k+1)(k+2))` = `(k+1)²/((k+1)(k+2))` = `(k+1)/(k+2)` ✔
- 따라서 모든 자연수 n 에 대해 성립

⚠️ 자주 하는 감점: ① n = 1 확인 생략 ② 가정을 어디서 썼는지 표시 안 함 ③ 결론 문장 누락

## 개념 3. 분수꼴 수열의 극한과 단조성 (5강)

### 극한: 분모의 최고차항으로 나누기
`(pn + q)/(rn + s)` (r ≠ 0) → 분자·분모를 n 으로 나누면 `(p + q/n)/(r + s/n)` → **p/r**

### 증가/감소 판정: 이웃한 두 항의 차 `aₙ₊₁ − aₙ` 의 부호
- `aₙ₊₁ − aₙ > 0` (모든 n) → 증가수열 / `< 0` → 감소수열
- 통분하면 분모는 `(다음 항 분모)×(이번 항 분모)` → 분모의 부호를 따로 확인하고, 분자 부호로 판정

📌 **풀이 예시**: `aₙ = (3n + 1)/(n + 2)`
- 극한: `(3 + 1/n)/(1 + 2/n)` → 3
- 차: `aₙ₊₁ − aₙ = (3n+4)/(n+3) − (3n+1)/(n+2)`
  = `[(3n+4)(n+2) − (3n+1)(n+3)] / ((n+3)(n+2))` = `5/((n+3)(n+2)) > 0` → **증가**
- 실제 항: 4/3, 7/4, 2, 13/6, … (증가하며 3 에 다가감 ✔)
- 단조수렴정리와 연결: 증가 + 위로 유계(< 3) → 수렴

📌 반대 예: `bₙ = (2n + 5)/(n + 1)` → `bₙ₊₁ − bₙ = −3/((n+2)(n+1)) < 0` → 감소, 극한 2

💡 문자(상수)로 된 수열이면: 같은 방법으로 차를 통분 → 분자가 **상수들의 식**으로 나옴 → 그 식의 부호 조건 + 분모 부호 조건(문제의 단서 조건 활용)을 함께 쓴다.

## 개념 4. 무한급수 판정 (6강)

### 판정 순서도 (6강 "수렴 판정 전략")
1. **`lim aₙ ≠ 0` 이면 즉시 발산** (발산 판정) — 항상 먼저 확인!
2. 특수형? **등비급수** (`|r| < 1` 수렴) / **p-급수** `Σ1/nᵖ` (`p > 1` 수렴, `p ≤ 1` 발산)
3. 양항급수
   - 분수식·무리식 → **비교판정법** (아는 급수와 크기 비교)
   - nᵏ/aⁿ, n! 같은 지수형 → **비율판정법** `lim aₙ₊₁/aₙ = c` (c < 1 수렴, c > 1 발산, c = 1 판정 불가)
4. 부호가 번갈아 → **교대급수 수렴정리** (|aₙ| 단조감소 & → 0) + 절대수렴인지도 확인 (절댓값 급수가 수렴? → 절대수렴 / 원래만 수렴 → 조건수렴)

### 비교판정법 쓰는 요령 — "부등식 만들기"
- **수렴**을 보이고 싶을 때: 분자는 **크게**, 분모는 **작게** → 위에서 누르기 `aₙ ≤ (수렴하는 급수의 항)`
- **발산**을 보이고 싶을 때: 분자는 **작게**, 분모는 **크게** → 아래에서 받치기 `aₙ ≥ (발산하는 급수의 항)`
- 어느 쪽인지 감 잡기: 최고차항끼리 비교 → `nᵃ/nᵇ = 1/n^(b−a)` → p = b − a 가 1 보다 크면 수렴 쪽

📌 **예시 1**: `Σ (2n + 1)/(n³ + n)` — 감: n/n³ = 1/n² → 수렴 쪽
`(2n+1)/(n³+n) ≤ (2n + n)/n³ = 3/n²` (n ≥ 1), `Σ3/n²` 는 p = 2 > 1 로 수렴 → **비교판정법에 의해 수렴**

📌 **예시 2**: `Σ (n + 3)/(n² + 1)` — 감: n/n² = 1/n → 발산 쪽
`(n+3)/(n²+1) ≥ n/(n² + n²) = 1/(2n)` (n ≥ 1), `Σ1/(2n)` 은 p = 1 이라 발산 → **비교판정법에 의해 발산**

📌 **예시 3 (비율)**: `Σ n²/3ⁿ` → `aₙ₊₁/aₙ = (n+1)²/(3n²) → 1/3 < 1` → **비율판정법에 의해 수렴**

📌 **예시 4 (교대)**: `Σ (−1)ⁿ/√n` → `1/√n` 은 단조감소하고 0 으로 → **교대급수 수렴정리로 수렴**.
절댓값 급수 `Σ1/√n` 은 p = 1/2 ≤ 1 로 발산 → **조건수렴**

📌 **예시 5 (발산 판정)**: `Σ n/√(n² + 1)` → `aₙ = 1/√(1 + 1/n²) → 1 ≠ 0` → **발산**
💡 근호가 있는 일반항은 먼저 **유리화/정리해서 일반항의 극한부터** 보면 판정이 바로 끝나는 경우가 많음

📌 **예시 6 (등비와 비교)**: `Σ (n/(2n+1))ⁿ` → `n/(2n+1) < 1/2` 이므로 `aₙ < (1/2)ⁿ`, 등비급수 `Σ(1/2)ⁿ` 수렴 → **비교판정법에 의해 수렴**

⚠️ 과제 지시: "판정법의 **이름**을 명시하고 **과정**을 함께" → 매 문항 끝에 "○○판정법에 의해 수렴/발산" 을 꼭 쓰기

## 개념 5. 합성함수와 항등식 (3강)

- `(f ∘ g)(x) = f(g(x))` — **안쪽 g 먼저**, 그 결과를 f 에 넣기
- 합성은 일반적으로 교환법칙 X → `f∘g = g∘f` 가 되려면 **조건**이 필요
- ⭐ "**모든 실수 x 에 대하여**" 성립 = **항등식** → 양변을 x 에 대해 정리한 뒤 **같은 차수의 계수끼리 같다**고 놓는다 (계수비교법)
  - `px + q = p'x + q'` 가 모든 x 에서 성립 ⇔ `p = p'` 그리고 `q = q'`

📌 **풀이 예시**: `f(x) = 2x + 1`, `g(x) = kx − 3` 에서 `f∘g = g∘f` 가 되는 k
- `f(g(x)) = 2(kx − 3) + 1 = 2kx − 5`
- `g(f(x)) = k(2x + 1) − 3 = 2kx + k − 3`
- x 의 계수: 2k = 2k (항상 같음) / 상수항: −5 = k − 3 → **k = −2**
- 검산: k = −2 → f(g(x)) = −4x − 5, g(f(x)) = −4x − 5 ✔

💡 문자 상수 4개로 된 문제도 똑같이: 전개 → 계수비교 → 남는 식이 "조건"

## 개념 6. 연속과 중간값 정리 (7·8강)

### (1) 연속이 되게 하는 상수 구하기
x = a 에서 연속 ⇔ ① f(a) 정의 ② `lim_{x→a} f(x)` 존재 ③ 둘이 같음
→ "**극한값 = 함숫값**" 방정식을 세워서 상수를 구한다 (8강 예제: `(x²−4)/(x−2)` 의 k = 4)

### 지수함수가 들어간 0/0 꼴 극한 ⭐
- 기본 공식: **`lim_{t→0} (eᵗ − 1)/t = 1`**
  - 근거: 7강 슬라이드에는 이 공식이 없음 (`sin x/x` 공식만 있음). 표준 결과이며 교재 본문에 있을 수 있으니 **교재에서 위치를 확인하고 인용**하세요 (교재 내용은 제가 확인할 수 없습니다). Python(sympy)으로 극한값 1 은 확인함.
- 활용 요령: 지수 안의 식과 분모를 **똑같이 맞추기** (7강 예제 4.4 `sin x / sin 2x` 와 같은 원리)
  - `(e^{3x} − 1)/x = 3 · (e^{3x} − 1)/(3x)` → t = 3x 로 치환 (x → 0 이면 t → 0) → 3 · 1 = 3

📌 **풀이 예시**: `h(x) = (e^{3x} − 1)/(2x)` (x ≠ 0), `h(0) = k` 가 x = 0 에서 연속이 되는 k
- `lim_{x→0} (e^{3x} − 1)/(2x) = (3/2) · lim (e^{3x} − 1)/(3x) = 3/2` → **k = 3/2**

### (2) 구간에서 연속임을 설명하기
- 구간을 **문제 되는 점**과 **나머지**로 나누어 설명
  - x ≠ 0 인 점: 분자 `e^{3x} − 1` 연속(지수함수·상수의 차), 분모 2x 연속이고 ≠ 0 → **연속함수의 몫은 연속** (8강 성질 (4))
  - x = 0: (1) 에서 극한값 = 함숫값이 되도록 k 를 정했으므로 연속
- 닫힌구간의 끝점은 구간 안쪽 방향의 한쪽 극한(예: 0 에서는 우극한)만 보면 됨

### (3) 중간값 정리로 해의 존재 보이기 — 답안 틀
1. 함수가 **닫힌구간 [a, b] 에서 연속**임을 먼저 밝힌다 (← (2) 결과 활용)
2. 양 끝 함숫값 f(a), f(b) 계산 (e 의 근삿값 e ≈ 2.718 사용 가능)
3. 목표값 k 가 **f(a) 와 f(b) 사이**에 있음을 보인다
4. "중간값 정리에 의해 f(c) = k 인 c 가 (a, b) 에 적어도 하나 존재"

📌 **풀이 예시**: 위 h (k = 3/2) 에 대해 `h(x) = 4` 가 (0, 1) 에서 해를 가짐
- h 는 [0, 1] 에서 연속 / `h(0) = 3/2`, `h(1) = (e³ − 1)/2 ≈ 9.54`
- `3/2 < 4 < 9.54` → 중간값 정리에 의해 `h(c) = 4` 인 c ∈ (0, 1) 존재
- 💡 끝점 값이 정확히 k 가 아니므로 해 c 는 열린구간 (0, 1) 안에 있음

## 📘 심화: 수학적 귀납법 집중 학습 (2026-10-10)

### 왜 필요한가
"모든 자연수 n"은 무한히 많아서 하나씩 확인할 수 없다 → **두 가지만 증명**하면 전부 증명된 것으로 인정하는 방법

| 단계 | 도미노 비유 | 할 일 |
|---|---|---|
| ① 기초 단계 | 첫 도미노가 넘어진다 | n = 1 대입 → 좌변 = 우변 계산 |
| ② 귀납 가정 | "k번째가 넘어졌다고 치자" | n = k 일 때 식이 성립한다고 **가정** (식을 그대로 적기) |
| ③ 귀납 단계 | k번째가 k+1번째를 넘어뜨린다 | n = k+1 의 좌변을 ② 가 보이도록 쪼개기 → ② 대입 → 우변 모양 만들기 |
| ④ 결론 | 전부 넘어진다 | "수학적 귀납법에 의해 모든 자연수 n 에 대해 성립" |

### 필요한 계산 기술
- 거듭제곱: `xᵏ · x = xᵏ⁺¹`, `xᵏ⁺¹ · x = xᵏ⁺²`
- 분배법칙: `(a + b)(c) = ac + bc`
- `x⁰ = 1` (식이 1 로 시작하면 그 1 은 x⁰ 항)
- "…" 이 들어간 식에서 **마지막 항 하나 떼어내기**: `(1부터 k+1번째 항까지) = (1부터 k번째 항까지) + (k+1번째 항)`

### 풀이 예시 (x 가 들어간 식, 과제와 다른 식)
`Qₙ(x) = x + 2x + 3x + … + nx` 에 대하여, 모든 자연수 n 에 대해 `2Qₙ(x) = n(n+1)x`
1. n = 1: 좌변 `2Q₁(x) = 2·x = 2x`, 우변 `1·2·x = 2x` ✔
2. n = k 가정: `2Qₖ(x) = k(k+1)x`
3. n = k+1: `Qₖ₊₁(x) = Qₖ(x) + (k+1)x` (마지막 항 떼기)
   `2Qₖ₊₁(x) = 2Qₖ(x) + 2(k+1)x` (양변에 2 곱하기 = 분배)
   `= k(k+1)x + 2(k+1)x` (← 가정 대입)
   `= (k+1)x(k + 2) = (k+1)((k+1)+1)x` ✔ (n = k+1 일 때의 우변 모양)
4. 결론
- 포인트: **x 는 상수처럼 그대로 들고 다니고, 귀납은 n 에 대해서만** 한다
- 포인트: 식 앞에 **곱해진 인수**(여기선 2)는 쪼갠 두 덩어리에 **각각 분배**한다
