## 1. 집합이란?

🧺 **비유**: 집합은 "**규칙이 분명한 바구니**"예요. 어떤 물건을 보고 "이건 바구니에 들어가!" / "안 들어가!"를
**누가 판단해도 똑같이** 말할 수 있어야 집합이 됩니다.

- **집합(Set)**: 어떤 대상이 그 모임에 속하는지 여부가 **명확하게** 결정되고, 각 구성원을 서로 구별할 수 있을 때 그 대상들의 전체
- **원소(Element)**: 집합을 이루는 각각의 대상

| 집합 O (객관적 기준) | 집합 X (주관적 기준) |
|---|---|
| 모든 자연수의 모임 | 맛있는 음식의 모임 |
| 12의 약수의 모임 | 키 큰 학생의 모임 |
| 방송통신대 재학생의 모임 | 보기 좋은 풍경, 부자, 건강한 사람의 모임 |

### 기호
- 집합은 대문자 `A, B, C, …`, 원소는 소문자 `a, b, c, …`
- `a ∈ A` : a는 A의 원소 (a가 A에 속한다) · `A ∋ a` 도 같은 뜻 (방향만 반대)
- `a ∉ A` : a는 A의 원소가 아니다

### 유한집합 / 무한집합
- **유한집합**: 원소 개수를 셀 수 있음 (예: 1~10까지 자연수)
- **무한집합**: 원소가 무수히 많음 (예: 모든 자연수)

## 2. 집합을 쓰는 두 가지 방법

| 방법 | 설명 | 예 |
|---|---|---|
| **원소나열법** | 중괄호 안에 원소를 다 적기 | `A = {1, 2, 3, …, 10}` |
| **조건제시법** | 원소의 공통 성질을 적기 | `B = {x | x는 자연수}` |

원소나열법 규칙
- 같은 원소는 **한 번만**: `{1, 1} = {1}`
- **순서 무관**: `{1, 2, 3} = {2, 1, 3} = {3, 2, 1}`

조건제시법 형식: `{x | x가 만족해야 하는 조건}` — `|` 는 "**뒤의 조건을 만족하는**"이라는 뜻

📌 예제 1.2: `{2, 4, 6, 8, …} = {x | x는 짝수} = {x | x = 2n, n은 자연수}`
📌 예제 1.3: `{x | −1 ≤ x ≤ 4, x는 실수}` 는 원소나열법으로 나타내기 어렵다 (실수는 끝없이 촘촘해서 나열 불가)

## 3. 부분집합

🎒 **비유**: B의 물건을 **하나도 빠짐없이** A 가방에서 찾을 수 있으면 B ⊂ A.

- **정의**: B의 모든 원소가 A의 원소이면 `B ⊂ A` (또는 `A ⊃ B`)
  ⇔ "x ∈ B 이면 x ∈ A"
- 모든 집합은 자기 자신의 부분집합: `A ⊂ A`
- **상등**: `A = B ⇔ A ⊂ B 이고 B ⊂ A` (서로가 서로를 포함)
- **진부분집합**: B ⊂ A 이면서 B ≠ A → `B ⊊ A`
- **부분집합이 아님을 보이기**: B의 원소 중 A에 없는 것 **하나만** 찾으면 끝 → `B ⊄ A`

📌 예제 1.4
- `{n | n은 자연수} ⊊ {m | m은 정수}`
- `{x | x > 1} ⊊ {x | x² > 1}` (예: x = −2 는 오른쪽에만 있음)
- `A ⊂ B, B ⊂ C, C ⊂ A` 이면 `A = B = C`

## 4. 전체집합 · 공집합 · 벤다이어그램

- **전체집합 U**: 지금 이야기하는 모든 대상을 담은 가장 큰 집합
- **공집합 ∅**: 원소가 하나도 없는 집합 (빈 바구니)
- ⭐ **공집합은 모든 집합의 부분집합** (`∅ ⊂ A`)
  - 이유: "∅ ⊄ A" 가 되려면 ∅ 안에 A에 없는 원소가 하나 있어야 하는데, ∅ 에는 원소 자체가 없으므로 불가능 → 항상 ∅ ⊂ A
- **벤다이어그램**: 전체집합은 직사각형, 부분집합은 원(타원)으로 그려서 관계를 한눈에 보기

📌 예제 1.6 (U = 정수 전체) — 공집합 찾기
- `{x | x = −x} = {0}` (공집합 아님)
- `{x | x = −|x|} = {x | x ≤ 0인 정수}`
- `{x | x² < 0} = ∅` (제곱은 음수가 될 수 없음)
- `{x | (3/2)x − 4 = 0} = ∅` (x = 8/3 은 정수가 아님 → **전체집합 U를 꼭 확인!**)

## 5. 집합의 연산

| 연산 | 기호 | 뜻 | 비유 |
|---|---|---|---|
| 합집합 | `A ∪ B` | A **또는** B에 속함 | 두 바구니를 하나로 합치기 |
| 교집합 | `A ∩ B` | A **이고** B에 속함 | 두 바구니에 다 있는 것 |
| 여집합 | `Aᶜ` | U에는 있고 A에는 없음 | 바구니 밖에 있는 전부 |
| 차집합 | `A − B` | A에는 있고 B에는 없음 | A 바구니에서 B 것 빼기 |

### 성질
- 합집합: `A ∪ A = A`, `A ∪ U = U`, `A ∪ ∅ = A`, `A ∪ B = B ∪ A`, `(A ∪ B) ∪ C = A ∪ (B ∪ C)`
- 교집합: `A ∩ A = A`, `A ∩ U = A`, `A ∩ ∅ = ∅`
- **서로소(배반, disjoint)**: `A ∩ B = ∅` (공통 원소가 없음)
- 여집합: `(Aᶜ)ᶜ = A`, `A ∪ Aᶜ = U`, `A ∩ Aᶜ = ∅`
- ⭐ `B ⊂ A ⇔ Bᶜ ⊃ Aᶜ` (포함 방향이 **뒤집힘**)
- ⭐ 차집합 ↔ 여집합: `A − B = A ∩ Bᶜ = A − (A ∩ B)`, `Aᶜ = U − A`

📌 예제: U = {1,2,3,4,5}, A = {1,2,3}, B = {2,4}
→ `A ∪ B = {1,2,3,4}`, `A ∩ B = {2}`, `Aᶜ = {4,5}`, `A − B = {1,3}`

## 6. 분배법칙 · 드모르간의 법칙

### 분배법칙 (수의 `a(b + c) = ab + ac` 와 닮음)
- `A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)`
- `A ∪ (B ∩ C) = (A ∪ B) ∩ (A ∪ C)`  ← 수에서는 안 되는 모양인데 집합에서는 성립!

### 드모르간의 법칙 ⭐⭐
- `(A ∪ B)ᶜ = Aᶜ ∩ Bᶜ`
- `(A ∩ B)ᶜ = Aᶜ ∪ Bᶜ`

🔄 **외우는 법**: 괄호 밖의 ᶜ 가 안으로 들어가면 **각각에 ᶜ 가 붙고, ∪ ↔ ∩ 가 뒤집힌다.**
💬 비유: "사과 **또는** 배를 **안** 먹었다" 가 아니라 "사과 또는 배를 먹은 게 **아니다**" = "사과도 안 먹었고 **그리고** 배도 안 먹었다"

📌 예제 1.14 (증명형): `(A − B) ∪ (A − C) = A − (B ∩ C)`
```
(A − B) ∪ (A − C) = (A ∩ Bᶜ) ∪ (A ∩ Cᶜ)     ← 차집합을 여집합으로
                  = A ∩ (Bᶜ ∪ Cᶜ)             ← 분배법칙(거꾸로)
                  = A ∩ (B ∩ C)ᶜ              ← 드모르간
                  = A − (B ∩ C)               ← 다시 차집합으로
```
👉 증명 3종 세트: **① 차집합 → 교집합+여집합으로 바꾸기 ② 분배법칙 ③ 드모르간**

## 7. 원소의 개수와 고전적 확률

- `n(A)` : 유한집합 A의 원소 개수
- ⭐ **합집합**: `n(A ∪ B) = n(A) + n(B) − n(A ∩ B)` (겹친 부분을 두 번 셌으니 한 번 빼기)
- 서로소이면: `n(A ∪ B) = n(A) + n(B)`
- **곱집합**: `A × B = {(a, b) | a ∈ A, b ∈ B}` (순서쌍들의 집합), `n(A × B) = n(A) · n(B)`
  - 비유: 티셔츠 3벌 × 바지 2벌 = 코디 6가지

📌 예제: U = 20 이하 자연수, A = 2의 배수, B = 3의 배수
- n(A) = 10, n(B) = 6 (3, 6, 9, 12, 15, 18), n(A ∩ B) = 3 (6의 배수: 6, 12, 18)
- `n(A ∪ B) = 10 + 6 − 3 = 13`
- `n(A × B) = 10 × 6 = 60`
- ⚠️ 강의 슬라이드에는 n(B)=8, n(A×B)=80 으로 적혀 있으나, 3의 배수는 20 이하에 6개이므로 **60이 맞음** (Python으로 직접 세어 확인. `materials/README.md` 정오표 참고)

### 고전적 확률
- `P(A) = n(A) / n(U)` (표본공간 U 중에서 사건 A가 차지하는 비율, 모든 경우가 똑같이 일어날 때)
- 예: 주사위 짝수 → U = {1,…,6}, A = {2,4,6} → P(A) = 3/6 = 1/2
