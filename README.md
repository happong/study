# study-python

Python 개인 튜터 학습 저장소. Claude Code가 `CLAUDE.md`를 읽고 개인 맞춤 Python 학습을 진행합니다.

## 구조

- `CLAUDE.md` — 학습 규칙 (Claude Code가 세션 시작 시 저장소 루트에서 자동으로 읽음)
- `python/` — 실제 Python 학습 데이터
  - `progress.md` — 현재 레벨, 정답률, 진행 상황
  - `concepts/learned.md` — 지금까지 배운 문법 개념 정리
  - `mistakes/wrong-patterns.md` — 반복되는 실수 패턴 모음
  - `logs/` — 날짜별 학습 로그 (문제, 제출 코드, 채점 결과)
