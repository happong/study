### 최종 제출 코드 및 결과 (실제 실행으로 확인, 일부 수정 포함)

```python
# Q1 ~ Q3, Q5 ~ Q9: 1차 정답 (상세는 채점 과정 참고)

# Q4 (수정 필요했음: 실수 계산 오류)
drops = [("검", 0.05), ("방패", 0.1)]
for item, rate in drops:
    print(item, "-", rate*100, "%")
# 실제 출력: 검 - 5.0 % / 방패 - 10.0 %
# 사용자 답: 검 - 5 % / 방패 - 1 %  → float 표시(5.0)와 계산 실수(0.1*100=10인데 1로 계산) 둘 다 틀림

# Q6 (1차 정답)
def find_expired(items):
    endItem = "없음"
    for name, expired in items:
        if expired == True:
            endItem = name
    return endItem
# ✅ 마나포션 (조기 return/덮어쓰기 패턴 스스로 정확히 진단 및 수정)

# Q10 (2회 수정: 최솟값 찾기에서 초기값을 0으로 설정 → 항상 실패)
# 1차: low_ave = 0 → "ave < 0"이 절대 참이 될 수 없어 "None" 반환
# 사용자 질문: "초기 데이터를 어떻게 넣어야 하나" → 최댓값 찾기(0에서 시작)와 반대로,
#            최솟값 찾기는 "첫 번째 값으로 시작"하거나 "매우 큰 값으로 시작"해야 함을 설명
# 추가 질문: 리스트[i][j] 이중 인덱싱 개념 — feedback[0][1], feedback[2][0] 예제로 확인시킴
def save_lowest_review(feedback):
    low_user = feedback[0][0]
    low_ave = feedback[0][1]
    for userId, ave in feedback:
        if ave < low_ave:
            low_ave = ave
            low_user = userId
    with open("lowest_review.txt","w") as low:
        low.write(low_user)
    with open("lowest_review.txt","r") as low:
        return low.read()
feedback = [("u1",4),("u2",1),("u3",3)]
print(save_lowest_review(feedback))
# ✅ u2
```

### 최종 결과: 10/10 = 100% 🎉

### 새로 발견된 실수 패턴 / 개념 질문

- **Q4**: 실수(float) 계산 결과를 예측할 때 `.0`이 붙는다는 것을 놓침 + 자체 암산 실수(0.1×100=10인데 1로 잘못 계산)
- **Q10 신규 패턴 — 최솟값 찾기 초기값 오류**: 최댓값 찾기(초기값 0에서 시작, 크면 갱신)에는 익숙하지만, **최솟값 찾기는 반대로 초기값을 "첫 값" 또는 "매우 큰 값"으로 잡아야** 한다는 것을 몰라서 초기값을 관성적으로 0으로 설정 → 조건이 항상 거짓이 되어 갱신이 전혀 안 됨. 사용자가 먼저 원인을 못 찾고 질문했고, 개념 설명 후 `feedback[0][1]`(리스트의 첫 튜플의 두 번째 값)로 정확히 수정함
- **개념 질문(성장 포인트)**: `리스트[i][j]` 형태의 이중 인덱싱 원리(앞 인덱스=리스트 안에서 몇 번째 튜플, 뒤 인덱스=그 튜플 안에서 몇 번째 값)를 스스로 질문하고, 반대 사례(`feedback[2][0]`)까지 정확히 유추해서 맞힘 — 완전히 이해한 것으로 판단됨
