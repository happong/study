## 이전 문제 자율 재연습 (세트 #2의 Q7~10, 새 데이터로 재작성)

사용자가 세트 #2에서 다뤘던 `is_online`, `enemies` 순회, `get_price`, `add_exp` 문제를
새로운 데이터로 직접 다시 작성해서 제출함 (요청하지 않은 자율 복습).

### 제출 코드 및 실행 결과

```python
def is_online(user_dict):
    if user_dict["status"] == "온라인":
        return True
    else:
        return False

onlineSt = {"status":"온라인","hp":10,"mp":40,"des":"빌드머신"}
onlineSta = {"status":"오프라인","hp":10,"mp":40,"des":"빌드머신"}
print(is_online(onlineSt))    # True
print(is_online(onlineSta))   # False

enemies = {"고블린":30,"슬라임":0,"오크":80}
for monster,hp in enemies.items():
    if hp == 0:
        print(monster,": 처치됨")
    else:
        print(monster, ": 전투중")
# 고블린 : 전투중 / 슬라임 : 처치됨 / 오크 : 전투중

def get_price(shop_dict, item_name):
    if item_name in shop_dict:
        return shop_dict[item_name]
    else:
        return "판매하지 않음"

item_price = {"지우개":500,"연필":300,"스탠리물병":25000,"핸드크림":12000}
print(get_price(item_price,"호올스"))  # 판매하지 않음
print(get_price(item_price,"연필"))    # 300

def add_exp(player_dict, player_name, exp):
    if player_name in player_dict:
        player_dict[player_name] = player_dict[player_name] + exp
        return player_dict
    else:
        player_dict[player_name] = exp
        return player_dict

name_list = {"하은":300, "민번":120,"지혜":50,"슬립":190}
print(add_exp(name_list,"하은",100))   # {'하은': 400, ...}
print(add_exp(name_list,"메론",350))   # {..., '메론': 350}
```

**결과: 4/4 모두 ✅** — 지난번 세트 #2에서 틀렸던 `get_price`/`add_exp` 패턴을 완전히 스스로 교정해서 재작성함.

### 오답 원인 — Q4

- 문제에서 확인하라고 한 키는 `"boss_cleared"`인데, 코드에는 `"boss_cleard"`(e 하나 빠짐)로 적혀 있음.
- `save_data`에는 애초에 `"chapter"` 키만 있어서, `"boss_cleared"`든 `"boss_cleard"`든 둘 다 없는 키라 **우연히 "없음"이라는 같은 출력**이 나옴.
- 이게 위험한 이유: 만약 나중에 `save_data`에 `"boss_cleared": True`가 진짜로 들어온다면, 이 코드는 오타난 키(`"boss_cleard"`)를 찾기 때문에 여전히 `"없음"`을 출력하는 **숨은 버그**가 됨. 지금은 우연히 맞았을 뿐, 이 코드는 틀린 코드임.
```python
save_data = {"chapter": 3}
if "boss_cleared" in save_data:   # 정확한 철자로
    print("있음")
else:
    print("없음")
```
- 교훈: 출력 결과가 맞아도 **키 이름 철자가 문제와 정확히 일치하는지** 항상 다시 확인하는 습관이 필요함.

### 새로 발견된 실수 패턴
- 키 이름 오타가 있어도 데이터에 우연히 둘 다 없어서 출력 결과가 맞아떨어지는 "우연한 정답" — 실제로는 잘못된 키를 확인하고 있어 숨은 버그가 됨
