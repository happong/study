### 새로 발견된 실수 패턴 / 특이사항

- **Q3**: "고쳐서 보내달라"는 요청에 같은(쓰기 단계 누락) 코드를 반복 제출함. 사용자가 "따로 쓰기 부분을 적었다"고 착각 → 받은 내용을 그대로 인용해서 보여주니 바로 인지하고 정확히 수정함. **채점 결과를 사용자에게 명확한 근거(받은 코드 원문)로 보여주는 것이 오해를 빠르게 해소하는 데 효과적이었음**
- **Q9 신규 패턴**: `read()`로 문자열을 받은 뒤 그 문자열에 `.readlines()`(파일 전용 메서드)를 호출 → `AttributeError`. `read()`와 `readlines()`를 같이 쓰면 안 되고 하나만 선택해야 함
- **Q10 신규 패턴**: 요구된 로직(최댓값 찾기)은 정확했으나, 문제의 핵심 목적인 "파일에 쓰고 다시 읽기"를 건너뛰고 계산 결과만 바로 return함 → 출력값은 우연히 일치했지만 실제로 파일(`ranking.txt`)이 생성되지도 않았음. Lv.12 학습 목적과 무관한 방식으로 "정답처럼 보이는" 결과를 낸 사례

### 성장 포인트
Q6(early return 패턴), Q8(dict.items()+str() 패턴)을 별도 지적 없이 1차에 정확히 적용 — Lv.10~12에 걸쳐 반복 학습한 패턴들이 안정적으로 체화되고 있음.
