# Q5 (여러 차례 수정, 최종 문자열 포맷 공백 1군데는 예외 처리)
def intro(player_tuple):
    name, level = player_tuple
    return "이름: " +name+", 레벨:"+str(level)
print(intro(("하은",25)))

def get_status(user_dict):
    if user_dict["hp"] > 0:

char = {"hp": 0}

# Q7 (여러 차례 수정)
def count_error(logs):
    errorNum = 0
    for re in logs:          # 처음엔 logs() 로 호출해서 TypeError → 수정
        if re == "에러":
            errorNum = errorNum + 1
    return errorNum
logsList = ["에러","경고","정보","에러","에러"]
print(count_error(logsList))   # 3
# ✅

# Q8
def build_summary(build_tuple):
    name, result, time = build_tuple
    if result == True:
        return name + ": 성공 ("+str(time)+"분)"
    else:
        return name + ": 실패"
print(build_summary(("server_BUILD",True,12)))   # server_BUILD: 성공 (12분)
print(build_summary(("asset_BUILD",False,5)))     # asset_BUILD: 실패
# ✅

# Q9 (여러 차례 수정)
def find_popular(quest_records,target):
    quelist = []
    for questName, compe in quest_records:
        if compe >= target:
            quelist.append(questName)
    return quelist              # 처음엔 for 안, if 옆에 있어서 첫 반복에서 조기 종료 → 수정
quest_records = [("튜토리얼", 980), ("1장", 620), ("보스전", 150)]
print(find_popular(quest_records, 500))   # ['튜토리얼', '1장']
# ✅

# Q10 (min/max 내장함수 소개 후 완료)
def get_min_max(scores):
    return min(scores), max(scores)
scores = [55, 82, 60, 45, 91]
low, high = get_min_max(scores)
print(low,high)   # 45 91

### 오답 원인 요약 및 새로 발견된 실수 패턴

- **Q3**: 인덱스(자리 번호, 0부터 시작)와 실제 값(90)을 혼동해서 존재하지 않는 인덱스(`scoreLi[90]`)에 접근 → `IndexError`
- **Q7**: 리스트 매개변수를 함수처럼 호출(`logs()`) — 딕셔너리를 함수처럼 호출했던 이전 실수(`dict("key")`)와 같은 계열의 착각
- **Q9**: `return`이 `if` 밖으로는 나왔지만 여전히 `for` 반복문 **안**에 있어서 첫 반복에서 조기 종료 — Lv.10에서 여러 번 나왔던 "조기 return" 패턴이 Lv.11에서도 재발
- **Q10**: `min()`/`max()` 내장 함수를 몰라서 중첩 반복문으로 직접 구현하려다 막힘 → 설명 후 해결
- **(예외 처리, 채점 제외)** 문자열 조합 시 콜론 뒤 공백 등 세부 포맷팅은 사용자 요청으로 이번엔 채점에서 제외. 실무에서는 로그/API 등에서 정확한 문자열 매칭이 필요할 수 있음을 별도 안내
