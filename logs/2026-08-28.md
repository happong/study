### 오답 원인

**Q9 — `get_price(shop_dict, item_name)`**
- `if shop_dict[key] == item_name:`에서 `key`라는 변수를 사용했지만, 이 함수 안에는 `key`를 만든 적이 없음 (반복문이 없는데 5번/8번에서 쓰던 `for key, values in ...`의 `key`를 그대로 가져다 씀)
- 이 문제는 반복문이 필요 없음 — 매개변수로 받은 `item_name`을 바로 키로 사용하면 됨
- 올바른 코드:
  ```python
  def get_price(shop_dict, item_name):
      if item_name in shop_dict:
          return shop_dict[item_name]
      else:
          return "판매하지 않음"
  ```

**Q10 — `add_exp(play_dict, player_name, exp)`**
- 딕셔너리 접근에 소괄호 `()`를 사용 (`play_dict(player_name)`) → 대괄호 `[]`를 써야 함
- 키 존재 확인을 `play_dict(player_name) == True`로 시도 → `in`을 써야 함
- 올바른 코드:
  ```python
  def add_exp(play_dict, player_name, exp):
      if player_name in play_dict:
          play_dict[player_name] = play_dict[player_name] + exp
          return play_dict
      else:
          play_dict[player_name] = exp
          return play_dict
  ```

```python
    build_count = 0

        if success == False:
            build_count = build_count + 1
    return build_count                             # if 블록 밖으로 이동
```

**Q10 — `find_low_progress`**
```python
def find_low_progress(quest_data, target):
    quest_list = []
    for name, count in quest_data.items():   # 키만 순회 → .items()로 값도 함께
        if count < target:
            quest_list.append(name)
    return quest_list
```

### 새로 발견된 실수 패턴
- `.items()`를 `.item()`으로 잘못 쓰는 오타 (Q7, Q9 두 번 반복)
- `if` 블록 **안**에 `return`을 넣어 반복문을 끝까지 못 도는 조기 종료 (Q7, Q9)
- 값이 필요한데 키만 순회하고 있는 것을 못 알아챔 (Q10)
- `for`문이 반복 변수를 자동으로 만들어준다는 걸 모르고 "정의 안 해서 에러"라고 잘못 판단 (Q8)
