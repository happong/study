# 12강 — 문장

## 1. 선언문과 실행문

- **문장(statement)**: 처리를 나타내는 표현. 프로그램은 데이터 처리를 위해 문장의 나열로 구성됨.
- 문장의 구분: **선언문**, **실행문**

```c
int y;
int add(int, int);
y = add(3, 4);
if (y > 5) y = 10; else y = 0;
```

### 선언문
- 변수나 서브프로그램의 이름을 만들어 이후에 이용할 수 있도록 준비

| 구분 | 의미 | 예시 |
|---|---|---|
| 변수 선언문 | 변수명, 타입 등을 바인딩 | `int y;` |
| 서브프로그램 선언문 | 서브프로그램의 프로토콜을 명시 | `int add(int, int);` |

### 실행문
- 변수, 연산자, 서브프로그램을 이용하여 데이터를 처리
- 실행문의 구분: **대입문**, **제어문**

```c
y = add(3, 4);
if (y > 5) y = 10; else y = 0;
```

## 2. 대입문

- **대입문(assignment statement)**: 변수의 값을 변경. 프로그램에서 가장 자주 사용되는 문장. 대입 연산자를 이용.

### 대입 연산자
- 대입 연산자의 오른쪽 부분의 값을 대입 연산자의 왼쪽 변수의 값으로 대입
- `=`, `:=`, `move ~ to` 등

| 표기 | 사용 언어 |
|---|---|
| `A = 5` | C, C++, Java, Python 등 |
| `A := 5` | Algol, Pascal, Ada 등 |
| `MOVE 5 TO A` | Cobol |

### C, C++, Java의 대입문

- 대입 연산자를 이용한 수식의 마지막에 쌍반점(`;`)을 찍으면 대입문이 됨
  - 수식: `A = 5` → 값은 `5`
  - 문장: `A = 5;`

**연속 대입문**: 하나의 값을 여러 변수에 대입. 대입 연산자의 특성(**우결합**, 대입한 값이 수식의 값)을 활용.

```c
C = B = A = 5;
→ C = B = 5;
→ C = 5;
```
(A, B, C 모두 정수형 변수로서 각자의 주소에 5가 저장됨)

**C++ 조건 연산자를 이용한 대입문**: 값이 대입될 변수를 조건에 따라 선택하여 대입

```c
(cond ? t : f) = 5;
```
는 다음과 같음:
```c
if (cond)
    t = 5;
else
    f = 5;
```

**복합 대입 연산자**: 산술 연산자와 대입 연산자가 결합

| 연산자 | 의미 |
|---|---|
| `+=` | 변수의 현재 값에 더한 값을 대입 |
| `-=` | 변수의 현재 값에서 뺀 값을 대입 |
| `*=` | 변수의 현재 값에 곱한 값을 대입 |
| `/=` | 변수의 현재 값을 나눈 값을 대입 |
| `%=` | 변수의 현재 값을 나눈 나머지 값을 대입 |
| `>>=` | 변수의 현재 값을 오른쪽으로 비트 단위로 이동한 값을 대입 |
| `<<=` | 변수의 현재 값을 왼쪽으로 비트 단위로 이동한 값을 대입 |

**단항 대입 연산자**

- `++`: 피연산자가 가진 값에 1을 더한 값을 대입 → `a++;` = `a += 1;` = `a = a + 1;`
- `--`: 피연산자가 가진 값에서 1을 뺀 값을 대입 → `--b;` = `b -= 1;` = `b = b - 1;`

### 타입 변환

- 주어진 타입의 값을 다른 타입의 값으로 변환
- 대입할 값의 타입과 변수의 타입이 서로 일치하지 않는 경우 필요
- 종류: **묵시적 타입 변환**, **명시적 타입 변환**

예) `i = 1.5` (정수형 변수 i에 실수형 값 1.5를 대입하려는 경우 → 변환 필요)

| 구분 | 의미 |
|---|---|
| 묵시적 타입 변환 | 값의 타입을 변수의 타입으로 변환하여 대입. C, C++: 확대변환 및 축소변환 가능 / Java: 확대변환만 가능 |
| 명시적 타입 변환 | 값의 타입을 프로그래머가 명시한 타입으로 변환. 확대변환 및 축소변환 모두 가능 |

묵시적 타입 변환 예 (C, C++):
```c
double pi=3.14, radius=1.5;
int area;
area = radius * radius * pi;
```

명시적 타입 변환 예:
```c
double pi=3.14, radius=1.5;
int area;
area = (int)(radius * radius * pi);
```

## 3. 제어문

- **제어문(control statement)**: 프로그램의 수행 흐름을 제어
- 제어문의 구분: **조건문**, **반복문**

### 조건문
- 조건에 따라 서로 다른 처리를 하도록 제어하는 문장
- 대표적인 조건문: **if문**

| 구분 | 내용 |
|---|---|
| if문 | 조건이 참인 경우에만 then 다음의 문장을 수행. else가 있는 경우, 조건이 거짓인 경우에만 else 다음의 문장을 수행 |

if문 표현은 언어마다 다양함.

```c
// C
if (y > 5) {
  y = 10;
  printf("%d\n", y);
}
else {
  y = 0;
  printf("zero\n");
}
```

```python
# Python
if y > 5:
  y = 10
  print(y)
else:
  y = 0
  print("zero")
```

**switch문**: 조건의 값에 따라 모두 다르게 처리할 수 있음. 한 번에 여러 갈래로 흐름을 나눌 수 있음.

```c
switch (n) {
  case 0: printf("zero\n");
          break;
  case 1: printf("just one\n");
          break;
  case 2: printf("even\n");
          break;
  case 7: printf("lucky\n");
          break;
  default: printf("hm...\n");
}
```

### 반복문
- 원하는 문장을 반복해서 수행하도록 제어하는 문장
- 대표적인 반복문: **for문**, **while문**, **do-while문**

| 구분 | 내용 | 반복 횟수 |
|---|---|---|
| for문 | 제어변수를 초깃값부터 종료값까지 증가분만큼씩 늘리며 원하는 문장을 반복 수행 | - |
| while문 | 조건이 참인 동안 원하는 문장을 반복 수행 | 0번 이상 |
| do-while문 | 조건이 참인 동안 원하는 문장을 반복 수행 | 1번 이상 |

```c
// for문
for (i = 0; i < 100; i++) {
  y += i;
  printf("%d\n", y);
}
// 결과: 0, 1, 3, 6, 10, ⋮, 4851, 4950
```

```c
// while문
while (max > min)
  max--;
```

```c
// do-while문
do
  max--;
while (max > min)
```

**문장 예시** (반복문 활용):
```c
char *loop(char *b, char *a) {
  char *s = b;
  while (*b++ = *a++)
    ;
  return s;
}
```

### 무조건 분기문과 goto 논란

| 구분 | 내용 |
|---|---|
| 무조건 분기문 | 아무 조건 없이 분기하도록 제어하는 문자. goto문: 기계어 및 어셈블리어에서 유래한 명령어 |

```c
int main()
{
    int i = 1;
L0: printf("%d\n", i);
    i = i + 1;
    if (i == 11)
        return 0;
    goto L0;
}
```

**goto 논란**
- 프로그램 작성에 goto를 포함시켜야 하는지 여부에 대한 논란
- goto의 목적지를 아무 곳으로나 지정할 수 있으므로 프로그램의 구조를 파악하기 힘듦
- goto를 제외한 언어: Modula-2, CLU, Java, Rust 등

## 정리하기

- 문장이란 처리를 나타내는 표현으로 선언문과 실행문으로 구분함
- 선언문은 변수나 서브프로그램의 이름을 만들어 이후에 이용할 수 있도록 준비
- 실행문은 실제로 변수나 서브프로그램을 이용하며 데이터를 처리하는 것으로, 변수의 값을 변경하는 대입문과 프로그램의 수행 흐름을 제어하는 제어문이 있음
- 조건문은 조건에 따라 서로 다른 처리를 하도록 제어하는 문장임
- 반복문은 원하는 문장을 반복해서 수행하도록 제어하는 문장임
- while문은 반복문장이 한 번도 수행되지 않을 수도 있지만 do-while문은 반복문장이 적어도 한 번은 수행됨
- goto문은 정해진 곳으로 무조건 분기하는 무조건 분기문으로 goto 논란을 촉발함
