# 08강 — 변수의 영역(scope)

## 1. 영역의 개요

- **영역(scope)**: 프로그램에서 변수를 사용(값을 대입하거나 읽어올 수 있는) **범위**. 영역의 시작은 변수가 **선언되는 곳**.
  - C 언어: 선언 전에 변수를 쓰면 오류 / Python: 묵시적 선언이라 오류 없이 동작하는 경우가 있음
- **영역 vs 수명**: 전역변수는 영역=수명=프로그램 전체. 함수 내부 변수는 영역=함수 내부, **수명**=함수가 호출된 시간 동안으로 한정.

### 블록(block)
- 프로그램 문장들의 묶음으로, **영역을 구분해주는 단위**. 블록 안에서 변수 선언 가능. 영역의 시작=선언 지점, 끝=블록이 끝나는 지점.
- 언어마다 블록으로 치는 기준이 다름: **Algol 60**=복합문(begin~end) / **C, C++, Java**=복합문({~}), 함수, 클래스 / **Pascal**=주프로그램, 서브프로그램(복합문 begin~end는 블록이 아님에 주의!)

### 지역변수 vs 비지역변수 (상대적 개념)
- **지역변수**: 해당 블록 안에서 선언되어 쓰이는 변수
- **비지역변수**: 특정 지점에서 사용 가능하지만, 그 블록에서 선언되지 않은 모든 변수
- 지역변수는 **자신을 포함하는 바깥 블록 안에서는** 비지역변수로 취급될 수 있음

### 참조환경(referencing environment)
- 프로그램의 한 위치에서 사용 가능한 **모든 식별자(지역변수 + 비지역변수)의 모음**.

## 2. 영역 규칙(scope rule)

- 변수의 **참조 위치**(= 어느 선언을 가리키는지)를 결정하는 방법. 주로 **비지역변수**의 위치를 어떻게 결정할지를 다룸.
- **자유변수(free variable)**: 현재 블록에서 선언되지 않고 사용하려는 변수. 참조 위치를 찾으면 비지역변수, 못 찾으면 **오류**.

### ① 정적 영역 규칙(static/lexical scope rule)
- 블록들의 **정적 내포 관계**(= 문맥적인 포함 관계, 프로그램을 실행하지 않아도 판단 가능)로 참조 위치 결정.
- 용어: **정적 조상** = 현재 블록을 문맥적으로 포함하는 모든 블록 / **정적 부모** = 그중 가장 가까운 블록.
- **적용법**: ① 현재 블록에 선언이 있으면 지역변수 ② 자유변수면 정적 부모로 올라가며, 선언을 찾으면 비지역변수, 못 찾으면 그 블록의 정적 부모에 대해 반복 ③ 최외곽까지 못 찾으면 오류.

### ② 동적 영역 규칙(dynamic scope rule)
- 블록들의 **동적 내포 관계**(= 서브프로그램의 **호출** 관계, 수행 시점에만 판단 가능)로 참조 위치 결정.
- **적용법**: ① 현재 블록에 선언 있으면 지역변수 ② 자유변수면 **현재 블록을 호출한 블록**에 대해 반복 ③ 최초 호출자까지 못 찾으면 오류.
- 정적 규칙과 달리 "코드상 위치"가 아니라 "누가 누구를 호출했는가"에 따라 참조 위치가 달라짐 → 같은 코드라도 호출 경로에 따라 결과가 달라질 수 있음.

### 영역 규칙 비교표
| | 정적 영역 규칙 | 동적 영역 규칙 |
|---|---|---|
| 결정 시점 | 컴파일 시점 | 프로그램 수행 시점 |
| 특징 | 정적 타입 검사 가능, 빠른 수행 속도 | 정적 타입 검사 불가능, 느린 수행 속도 |
| 적용 언어 | Algol 60, Pascal, C, C++, Java, Python 등 대부분 | LISP 등 인터프리터 방식 구현 언어 |

### 영역 구멍(scope hole)
- 비지역변수가 **같은 이름의 지역변수** 때문에 가려져 보이지 않는 영역. 안쪽 블록에서 바깥과 같은 이름의 변수를 재선언하면, 바깥 변수는 그 안쪽 블록 범위 내내 "구멍"이 생긴다(가려진다).

## 3. 이름 공간(namespace)

- **전역변수(global variable)**: 어떤 블록에도 포함되지 않는 곳에서 선언된 변수. 영역=프로그램 전체, 모든 블록에서 비지역변수로 취급. 단, 같은 이름의 지역변수가 선언되면 역시 영역 구멍이 생김.
- **영역 구멍 없이 전역변수에 접근하는 방법**: **영역 연산자(scope resolution operator)**. C++에서는 `::변수명` (예: `::i`는 지역변수 i가 있어도 전역변수 i를 가리킴).
- **이름 공간(namespace)**: 관련성 높은 변수·함수를 하나의 묶음으로 관리하는, **자체 이름을 가진 영역**(C++의 `namespace`).
  - 접근법 ①: `이름공간::변수명` (예: `S1::k`)
  - 접근법 ②: `using namespace 이름공간;` 으로 해당 이름공간의 영역을 현재 영역까지 확장
  - 이름공간의 변수와 지역변수가 같은 이름이면 역시 영역 연산자로 구분해서 접근해야 함(그렇지 않으면 지역변수가 우선).
