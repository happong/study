# 07강 — 변수와 바인딩

## 1. 변수(variable)

- **정의**: 프로그램에서 처리할 데이터를 저장·관리할 수 있도록 **컴퓨터 하드웨어의 메모리를 추상화한 것**. 데이터를 저장하는 메모리 공간에 대한 상대적 이름.

### 변수의 속성 6가지
| 속성 | 의미 |
|---|---|
| 변수명(name) | 변수의 이름 = 식별자 |
| 타입(type) | 저장 가능한 데이터 집합의 종류(자료형) |
| 주소(address) | 변수가 쓰는 메모리의 위치("참조") |
| 값(value) | 변수에 저장된 데이터. 수행 중 변경 가능 |
| 수명(lifetime) | 변수가 메모리를 **할당받고 있는 기간** |
| 영역(scope) | 프로그램에서 변수를 **사용할 수 있는 범위** |

- **배런(Barron)의 변수 표기법**: (변수명) — (타입) — [주소: 값] 세 요소를 연결한 그림으로 변수를 표현.

## 2. 바인딩(binding)

- **정의**: 언어 구성 요소의 속성이 **구체적으로 결정되는 것**.
  예) `int`를 4바이트 정수형으로 바인딩 / `x12`를 변수명으로 바인딩 / `+`를 덧셈 연산자로 바인딩 / `x12`의 값을 11로 바인딩

### 바인딩 시각(binding time)
언어정의 시점 → 언어구현 시점 → 컴파일 시점 → 링크 시점 → 로드 시점 → **프로그램 수행 시점**

| 바인딩 시각 | 예시 |
|---|---|
| 언어 정의 시점 | 연산자의 의미, 수의 의미 |
| 언어 구현 시점 | 타입의 자릿수, 수의 표기법 |
| 컴파일 시점 | 변수의 타입 |
| 링크 시점 | 라이브러리 함수의 내용 |
| 로드 시점 | 변수의 주소 |
| 프로그램 수행 시점 | 변수의 값 |

**단순화된 구분(중요)**
- **정적 바인딩(static binding)**: 프로그램 수행 시점에 바인딩의 변화가 **없음**(언어정의~로드 시점까지 포함). 수행시간 효율성이 높고, **컴파일 방법**에 적합.
- **동적 바인딩(dynamic binding)**: 프로그램 수행 시점에 바인딩이 **되거나 해지**됨. 유연한 프로그래밍이 가능하고, **인터프리터 방법**에 적합.

## 3. 변수의 바인딩

변수가 쓰이려면 속성이 바인딩되어야 하며, 일반적으로 **변수명 → 타입 → 주소 → 값(여러 번 가능)** 순서로 바인딩된다.

### 변수명 바인딩
- **명시적 선언**: `int x12;` 처럼 선언문에 명시된 이름으로 바인딩
- **묵시적 선언**: 선언문 없이, 대입문 등에 처음 쓰인 이름으로 바인딩(`k = 123;`)

### 타입 바인딩
- 명시적/묵시적 선언 둘 다 가능. 묵시적인 경우 Fortran은 변수명이 i~n으로 시작하면 정수형, Python은 **대입하는 값**으로부터 타입을 정함.
- **정적 바인딩**: 컴파일 시점에 구문 분석으로 타입을 판단(명시적·묵시적 선언 모두 가능)
- **동적 바인딩**: 변수의 타입을 고정하지 않고 대입값에 맞춰 계속 바꿈 (APL, SNOBOL 4, **Python** 등)

### 주소 바인딩
- **할당(allocation)**: 가용 메모리 중 필요한 만큼을 변수에 배정 / **해제(deallocation)**: 할당된 메모리를 회수
- 변수의 **수명** = 변수가 메모리를 할당받고 있는 기간 = 주소가 바인딩된 기간
- **자동 할당**: 선언을 통해 정해진 타입에 맞춰 자동으로 메모리 할당 (`int x;`)
- **수동 할당**: 프로그래머가 지정한 크기만큼 할당 (`malloc()`, `new`)

**메모리 구조**: `코드 | 정적 데이터` (정적 세그먼트) + `힙 → ← 스택` (동적 세그먼트). 자동 할당은 상황에 따라 정적/동적 세그먼트를 모두 쓸 수 있고, 수동 할당은 **힙**을 사용.

**주소 바인딩 시각에 따른 변수 종류**
- **정적 변수(static variable)**: 로드 시점에 정적 세그먼트 주소로 바인딩되어 프로그램 종료까지 유지. 수명 = 프로그램 전체(초기 Fortran의 모든 변수).
- **동적 변수(dynamic variable)**: 수행 중 변수가 쓰이는 시점에 동적 세그먼트 주소로 바인딩.
  - **스택 동적 변수**: 스택에서 할당. 자동 할당 변수 중 정적 변수가 아닌 경우. 필요한 시점에 자동 할당/해제됨(예: 함수의 지역변수).
  - **힙 동적 변수**: 힙에서 할당. **수동 할당**을 쓰는 변수(`malloc`/`free`, `new`/`delete`), 또는 **동적 타입 바인딩**을 쓰는 언어(APL, SNOBOL 4, Python)의 변수.
