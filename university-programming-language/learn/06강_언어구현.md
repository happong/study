# 06강 — 프로그래밍 언어의 구현

## 1. 언어 정의와 구현

- **언어 정의** = 구문 규칙(올바른 형태 규정) + 의미 규칙(수행 시 올바른 동작 규정)
  - 구문 규칙 정의: 주로 **문맥자유문법/EBNF**
  - 의미 규칙 정의: 주로 **자연어**(그 외 기능적/표기적/공리적 의미론)
- **언어 L의 구현** = ① 프로그램 P_L이 L의 구문 규칙에 맞는지 검사하고 ② 맞으면 L의 의미 규칙에 따라 P_L을 실행하는 프로그램.

### 함수 모형 (개념을 식으로 정리한 것)
- CPU: `M[[P_M]](in) = out`
- 언어 구현: `L[[P_L]](in) = out`
- **인터프리터**: `Int_L[[P_L]](in) = out` — CPU처럼 직접 동작
- **컴파일러**: `Comp_L[[P_L]] = P_M` 으로 번역한 뒤, `M[[P_M]](in) = out`으로 CPU가 실행

## 2. 프로그래밍 언어 구현 방법

- **전통적 언어(명령형/절차형/객체지향)**: 저급 언어(기계어)의 연산·명령어를 **확장**하는 형태로 구현. 절차형=명령형+사용자정의연산(함수)/명령어(프로시저), 객체지향=절차형+사용자정의 데이터 타입.
- **새 패러다임 언어(함수형/논리형)**: 단순히 기계어를 확장하는 방식으로는 한계가 있어, 계산 모델과 하드웨어 사이에 **추상기계**를 두고 이를 "징검다리" 삼아 구현한다.

| | 함수형 언어 | 논리 언어 |
|---|---|---|
| 계산 모델 | 람다 계산법 | 연역 논리 |
| 추상기계 | CPS, G-machine, STGM, TIM 등 | WAM 등 |

- **가상기계(VM)**: 추상기계가 구체적인 구현물로 제시되어, 코드를 독자적으로 수행할 수 있게 된 경우 (예: JVM).

## 3. 컴파일러/인터프리터 구현 단계

```
원시 프로그램 → 어휘분석 → 구문분석 → 의미분석 → 중간표현
                └──────── 분석 단계(전단부, 언어에 종속) ────────┘
중간표현 → 중간코드최적화 → 코드생성 → 목적코드최적화 → 목적 프로그램
          └──────── 생성 단계(후단부, 목적 기계에 종속) ────────┘
```
- **컴파일러**: 분석 단계 + 생성 단계를 모두 거쳐 목적 프로그램(기계어)을 만들어냄.
- **인터프리터**: 분석 단계는 동일하게 거치지만, 목적 코드로 바꾸는 대신 **중간 표현을 인터프리터 엔진이 직접 순회하며 그 자리에서 실행**한다.

## 4. 언어 구현에 필요한 자료 구조

- **구문 트리**: 언어 구현의 중심이 되는 자료구조. 분석 단계 전체를 관통함.
- **심볼 테이블**(컴파일러 구현): 프로그램에서 선언된 식별자의 정보(타입, 선언 위치 등)를 저장.
- **환경(environment)**(인터프리터 구현): 심볼 테이블보다 확장되어, 식별자의 **값 정보까지** 알 수 있는 테이블.
- **실행 환경**(언어 구현에는 안 쓰이지만 실행 시 반드시 필요):
  - 메모리 구조: **정적 세그먼트**(코드, 정적 데이터) / **동적 세그먼트**(힙, 스택)
  - 레지스터: 전용(PC, SP, FP 등) / 범용

## 5. 언어 구현 실제

- **어휘 분석기**: 예약어·리터럴·연산자 등 어휘를 구별. 보통 **유한 상태 기계(FSM)**로 구현.
- **구문 분석기**: 토큰 열로부터 구문 트리를 구성. 트리 형태로 **파스 트리**(문법 기호 정보를 모두 포함) 또는 **추상 구문 트리(AST)**(번역에 필요한 정보만 포함, 더 간결함)를 사용.
- **순환 하강 구문 분석기(recursive descent parser)**: 문법 규칙을 그대로 코드로 옮긴 구현 방식.
  1. 각 비단말기호의 문법 규칙마다 하나의 프로시저를 만들고, 그 프로시저가 규칙의 "우변"을 그대로 모사하게 작성
  2. 우변을 모사할 때 단말기호면 일치 여부를 검사(`match()`), 비단말기호면 해당 프로시저를 호출
  - 예: 괄호가 맞는 문자열 문법 `<S> ::= '(' <S> ')' <S> | ε` → `void S() { if (LA=='(') { match('('); S(); match(')'); S(); } }` 로 그대로 변환됨.
