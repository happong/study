# 01강 — 프로그래밍 언어 개요와 학습법

## 1. 프로그래밍 언어란?

- **정의**: 컴퓨터가 수행할 수 있고, 사람이 읽을 수 있는 형태로 "계산"을 나타내는 **표기 체계**.
- 프로그램 = 컴퓨터가 수행할 명령어를 순서대로 나열해둔 것.

### 자연어 vs 프로그래밍 언어 (시험에 자주 나오는 비교표)

| 구분 | 자연어 | 프로그래밍 언어 |
|---|---|---|
| 형식 | 말과 글 | 주로 글 |
| 내용 | 모호함, 함축적 | 엄밀한 규칙, 정확한 의도 |
| 방향성 | 양방향(대화) | 단방향/양방향 |

- 사람 ↔ 프로그램 ↔ 컴퓨터: 사람이 프로그램을 작성하면(양방향), 프로그램은 컴퓨터에게 단방향으로 명령을 내린다.

## 2. 프로그래밍 언어를 배워야 하는 이유

- 비트겐슈타인: "내 언어의 한계가 내 세상의 한계다" — 사고 능력 확장, 문제 해결자로서 언어 선택, 언어를 깊게 이해, 현명한 설계자/관리자가 됨.
- 스티브 잡스: 프로그래밍은 "체계적으로 생각하는 방법"과 "변화를 표현하는 방법"을 가르쳐준다.

## 3. 프로그래밍 언어의 기능

**기본 기능**
- **작성력(writability)**: 프로그래머의 의도를 표현할 수 있는가
- **가독성(readability)**: 프로그램을 쉽게 해독할 수 있는가
- **실행 가능성(executability)**: 컴퓨터에서 실행될 수 있는가

**부가 기능**
- **추상화**: 대상을 간략히 추려 나타냄
- **모듈화**: 복잡한 대상을 나누어 구성함

**언어의 특성**
- **기계적**: 엄밀한 규칙에 따라 정의되어 기계적으로 처리 가능해야 함
- **구조적**: 자료구조·제어구조 등 복잡한 구조를 나타낼 수 있어야 함
- **가변적**: 시대의 필요에 따라 바뀔 수 있음 (예: Python은 명령형 언어로 시작해 객체지향 개념을 탑재)

## 4. 언어 스펙트럼

- **고급 언어(high-level language)**: 기계 독립적으로 정의·실행 가능 (C, Java, Python 등). 추상화 수준에 따라 다시 다양한 스펙트럼 존재.
- **저급 언어(low-level language)**: 기계에 종속적 (기계어, 어셈블리어).
- 프로그래머 → (요구사항) → 프로그래밍 언어 ← (제약사항) ← 컴퓨터 구조.

## 5. 프로그래밍 언어의 구성 요소

| 요소 | 설명 |
|---|---|
| **데이터** | 자료를 프로그램이 처리할 수 있는 형태로 나타낸 것 (이진 데이터 / 텍스트 데이터) |
| **연산** | 데이터 처리 방법. 연산자(특별한 연산을 수행하는 함수), 변수(연산 결과를 저장하는 이름), 대입연산. 수식(값 표현)과 문장(처리 표현)으로 나타남. 원시연산/사용자정의연산/라이브러리로 구분 |
| **명령어** | 특정 작업을 지시하는 단어 (if, while 등) |
| **서브프로그램** | 작은 코드 블록에 이름을 붙인 것(서브루틴). **함수**(값 반환) vs **프로시저**(값 미반환) |
| **타입** | 데이터 집합 + 연산 집합. 연산의 **타입 안전성**(함수 f: A→B이면 모든 a∈A에 대해 f(a)∈B) 보장을 위해 필요. **강타입**(오류 모두 검출)/**약타입**(일부만 허용)/**무타입**(타입 선언 없음) 언어로 분류 |
| **모듈** | 독립적인 프로그램 구성 단위. 내부/외부 구별, 독자적 이름공간, 변수·함수·타입을 포함 |

## 6. 프로그래밍 언어의 학습 방법

- **두 가지 측면**: 프로그램 형태(데이터·연산 → **구문론**) vs 수행 과정(메모리·수행흐름 → **의미론**)
- **학습 요령**: 눈보다 손(직접 타이핑), 그림으로 생각(자료구조 시각화), 점진적 변경(한번에 완벽히 X)
- **왜 프로그래밍 언어론을 배우나**: 새 언어를 쉽게 습득하기 위해 / 내가 쓰는 언어를 더 잘 이해하기 위해 / 현명한 언어 설계자가 되기 위해
