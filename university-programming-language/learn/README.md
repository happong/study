# learn/ — 강의별 학습 노트

수업 진도가 나갈 때마다 강의(N강) 하나당 파일 하나를 만듭니다.

- 파일명 형식: `N강_학습제목.md` (예: `01강_프로그래밍언어_개요와_패러다임.md`)
- 내용: 핵심 개념 설명 → 예시 코드/도식 → 관련 용어 정리
- `00_중간과제_준비가이드.md`: 중간과제물 문제별로 필요한 개념과 풀이 뼈대를 정리한 과제 전용 가이드

## 현재 상태 (2026-10-07 기준)

- **실제 수업 진도**: 4강까지 수강
- **자가학습(선행) 정리**: 1~8강 자료를 미리 읽고 개념 정리 완료 (중간과제가 8강 범위까지 다뤄서 과제 대비 목적으로 선행 학습함)

| 강 | 제목 | 비고 |
|---|---|---|
| 01강 | 프로그래밍 언어 개요와 학습법 | |
| 02강 | 언어의 발전과 구현 방법 | |
| 03강 | 프로그래밍 언어 패러다임 | ⭐ 중간과제 1번 핵심 |
| 04강 | 구문론과 의미론 (BNF/EBNF/구문도표) | ⭐ 중간과제 2번 핵심 |
| 05강 | 구문 분석 (어휘분석/파스트리/모호성) | |
| 06강 | 프로그래밍 언어의 구현 | |
| 07강 | 변수와 바인딩 | |
| 08강 | 변수의 영역(scope) | |

실제 수업이 5강~8강까지 진행되면, 다음 세션에서 "오늘 N강 배웠어"라고 알려주세요 — 이미 선행 학습한 내용이라도 복습 문제로 바로 반복 출제할 수 있습니다.
