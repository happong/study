# learn/ — 강의별 학습 노트

수업 진도가 나갈 때마다 강의(N강) 하나당 파일 하나를 만듭니다.

- 파일명 형식: `N강_학습제목.md` (예: `01강_프로그래밍언어_개요와_패러다임.md`)
- 내용: 핵심 개념 설명 → 예시 코드/도식 → 관련 용어 정리
- `00_중간과제_준비가이드.md`: 중간과제물 문제별로 필요한 개념과 풀이 뼈대를 정리한 과제 전용 가이드

## 현재 상태 (2026-11-23 기준)

- **자가학습 정리**: 1~15강(전체 범위) 개념 정리 완료 — 기말시험(1~15강 범위)을 앞두고 선행 학습함
- **기말 대비**: `00_중간과제_준비가이드.md`와 별도로, 1~15강 전체 범위 복습 문제 세트를 `tutor/`에 기록해가며 진행 중

| 강 | 제목 | 비고 |
|---|---|---|
| 01강 | 프로그래밍 언어 개요와 학습법 | |
| 02강 | 언어의 발전과 구현 방법 | |
| 03강 | 프로그래밍 언어 패러다임 | ⭐ 중간과제 1번 핵심 |
| 04강 | 구문론과 의미론 (BNF/EBNF/구문도표) | ⭐ 중간과제 2번 핵심 |
| 05강 | 구문 분석 (어휘분석/파스트리/모호성) | |
| 06강 | 프로그래밍 언어의 구현 | |
| 07강 | 변수와 바인딩 | |
| 08강 | 변수의 영역(scope) | |
| 09강 | 타입 (단순타입, 타입 안전성) | |
| 10강 | 복합타입 (배열/문자열/연관배열/구조체·공용체/포인터·참조) | |
| 11강 | 수식과 연산자 | |
| 12강 | 문장 (대입문/제어문) | |
| 13강 | 서브프로그램 개요 (매개변수 전달 모델) | ⭐ 기출 단골 |
| 14강 | 서브프로그램 구현 (활성 레코드/정적·동적 체인/디스플레이) | ⭐ 기출 단골 |
| 15강 | 객체지향과 다형성 (ADT/캡슐화/다형성 3종) | |

실제 수업 진도가 더 나가면, 다음 세션에서 "오늘 N강 배웠어"라고 알려주세요 — 이미 선행 학습한 내용이라도 복습 문제로 바로 반복 출제할 수 있습니다.
