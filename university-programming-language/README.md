# 방송통신대 「프로그래밍 언어」 학습 시스템

방송통신대학교 컴퓨터과학과 전공과목 **프로그래밍 언어**를 위한 개인 학습 저장소입니다.
`study-python`과 완전히 별개의 과목/시스템이며, 이 폴더 안에서만 규칙이 적용됩니다.

> 원래 요청에 있던 `university_Programming language`, `tutar` 표기는
> 경로 호환성과 오타를 고려해 `university-programming-language`, `tutor`로 정리했습니다.

## 목표

- 방송통신대 「프로그래밍 언어」 강의 진도를 따라가며 개념을 완벽하게 이해하는 것 (학점 만점 목표)
- 단순 암기가 아니라, 문제를 스스로 풀 수 있는 수준까지 반복 학습
- 배운 내용 / 틀린 문제를 모두 GitHub에 기록해 다음 세션에서도 이어서 학습

## 폴더 구조

```
university-programming-language/
├── README.md          # 이 파일 — 과목/시스템 설명
├── STUDY_GUIDE.md      # 튜터 운영 규칙 (학습 프롬프트) — Claude Code가 항상 참고
├── learn/              # 강의(N강)별 학습 개념 정리
│   └── N강_주제.md
└── tutor/              # 날짜별 문제 풀이 + 오답 기록
    └── YYYY-MM-DD_오답.md
```

## 진행 방식 요약

1. 사용자가 새 수업 내용(진도)을 알려주면 → `learn/`에 새 강의 노트 생성
2. 그 강의 노트를 바탕으로 이전 학습 내용과 섞어서 랜덤 문제 출제 (객관식/주관식/서술형 혼합)
3. 채점은 실제로 확인 후 진행하고, 틀린 문제는 `tutor/YYYY-MM-DD_오답.md`에 기록
4. 반복적으로 틀리는 개념은 `STUDY_GUIDE.md`의 "반복 오답 패턴"에 누적하고, 해당 개념을 다시 짧게 설명한 뒤 재출제
5. 채점이 끝날 때마다 커밋/푸시하여 GitHub에 저장

세부 규칙은 `STUDY_GUIDE.md`를 참고하세요.
