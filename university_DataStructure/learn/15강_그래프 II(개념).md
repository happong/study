# 15강 — 그래프 II

## 핵심 요약

- **그래프 탐색**이란 그래프에서 특정 정점을 찾는 연산으로, 트리와 달리 루트가 없으므로 임의의 정점(출발점)에서 시작해 모든 정점을 방문한다.
- 그래프 탐색(순회)에는 **깊이 우선 탐색(DFS)**과 **너비 우선 탐색(BFS)** 두 가지 방법이 있다.
- **DFS**는 한 방향으로 갈 수 있는 데까지 깊게 들어간 뒤, 막히면 되돌아오는 방식이며 내부적으로 **스택**을 사용한다(순환 호출 또는 스택을 직접 운영).
- **BFS**는 가까운 정점부터 한 단계씩 넓게 퍼져나가는 방식이며 내부적으로 **큐**를 사용한다.
- **신장 트리(spanning tree)**는 그래프 G의 모든 정점과 간선의 일부(또는 전부)를 포함하는 트리로, n개의 정점이면 최소 n-1개의 간선으로 구성된다.
- **최소 비용 신장 트리**는 가중치 그래프에서 간선 비용의 합이 가장 작은 신장 트리이며, 대표 알고리즘으로 **프림(Prim)**, **크루스컬(Kruskal)**, **솔린(Sollin)** 세 가지가 있다.
- 프림은 "이미 고른 정점들"에 인접한 간선 중 최소 비용을 계속 고르고, 크루스컬은 정점 집합과 상관없이 "전체 간선 중" 최소 비용을 계속 고르며(사이클만 피함), 솔린은 여러 나무(숲)를 동시에 키우며 합쳐나간다.
- (※ 이 강의는 이번 학기 마지막 강의로, 슬라이드 끝에 "한 학기 동안 수고 많으셨습니다" 인사가 포함되어 있다. 전체 총정리/복습 강의는 아니며, 14강 "독립 정점/널 그래프" 개념을 잠깐 다시 언급하는 정도다.)

## 상세 내용

### 1. 그래프 탐색

**그래프 탐색이란?**

비유: 미로를 탐험한다고 생각해보자. 트리는 "꼭대기(루트)"가 정해져 있어서 항상 거기서부터 시작하면 되지만, 그래프는 원이나 거미줄처럼 생겨서 어디가 "맨 위"인지가 없다. 그래서 그래프를 탐색할 때는 "아무 정점이나 하나 골라서 거기서부터" 출발해야 한다.

정확한 정의: 그래프에서 특정 정점을 찾는 기본 연산. 그래프 G = (V, E)와 V(G)에 있는 정점 v가 주어졌을 때, 임의의 정점에서 정점 v에 도달할 때까지 G의 정점을 방문하는 연산이다. 만약 그래프 안에 정점 v가 없다면, 그래프의 모든 정점을 방문한 후 탐색을 종료한다.

그래프 탐색(순회)에는 두 가지 방법이 있다.
- **깊이 우선 탐색(Depth First Search; DFS)**
- **너비 우선 탐색(Breadth First Search; BFS)**

### 2. 깊이 우선 탐색(DFS)

비유: 미로에서 "일단 한 방향으로 갈 수 있는 데까지 쭉 가본다. 막다른 길이면, 가장 최근에 갈림길이 있었던 곳으로 되돌아가서 다른 길로 가본다"는 전략이다. 마치 실뭉치를 풀면서 들어갔다가, 막히면 실을 따라 되감아 나오는 것과 비슷하다.

**깊이 우선 탐색 알고리즘**
1) 시작: 출발점 v를 방문함
2) 다음으로 v에 인접하고 아직 방문하지 않은 정점 w를 선택하여, w를 출발점으로 다시 깊이 우선 탐색(인접하고 아직 방문하지 않은 정점을 선택)을 시작함
3) 위의 두 과정을 모든 정점을 한 번씩 방문할 때까지 반복함

만약 인접한 모든 정점들이 이미 방문한 정점인 경우는, 가장 최근에 방문했던 정점 중에서 방문하지 않은 정점 w를 가진 정점을 선택하여 정점 w로부터 다시 깊이 우선 탐색을 시작한다. 이 과정은 **스택**을 사용하여 가장 최근에 선택의 지점에 있던 정점을 찾아내는 것과 같다. 방문하지 않은 정점이 없으면 탐색을 종료한다.

**예시 그래프** (정점 v1~v8, 무방향 그래프)

```
            v1
           /  \
         v2    v3
        /  \  /  \
      v4   v5-v6   v7
         \   |   |   /
              v8
```
(간선: v1-v2, v1-v3, v2-v4, v2-v5, v3-v6, v3-v7, v4-v8, v5-v8, v6-v8, v7-v8)

- 출발점이 v1인 경우 DFS 방문 순서: v1, v2, v4, v8, v5, v6, v3, v7
- 출발점이 v4인 경우 DFS 방문 순서: v4, v8, v7, v3, v1, v2, v5, v6

**인접 행렬** (1~8번 정점, 0=연결 안됨, 1=연결됨)

```
   1 2 3 4 5 6 7 8
1 [0 1 1 0 0 0 0 0]
2 [1 0 0 1 1 0 0 0]
3 [1 0 0 0 0 1 1 0]
4 [0 1 0 0 0 0 0 1]
5 [0 1 0 0 0 0 0 1]
6 [0 0 1 0 0 0 0 1]
7 [0 0 1 0 0 0 0 1]
8 [0 0 0 1 1 1 1 0]
```

**방향 그래프에서의 DFS**: 방향이 있으면 화살표를 따라서만 이동할 수 있다. 출발점이 v1인 경우 DFS 방문 순서: v1, v2, v4, v8, v5, v6, v7, v3 (화살표 방향에 따라 무방향 그래프와 순서가 달라질 수 있음).

**순환 호출을 이용한 깊이 우선 탐색 코드**

```c
void DFS(Graph* g, int s) {
    int i, adjacent;
    g -> visited[s] = 1;
    printf("%d", s);
    for(adjacent = 0; adjacent < g -> nv; adjacent++) {
        if(g -> adj[s][adjacent] && !g -> visited[adjacent]) {
            g -> visited[adjacent] = 1;
            DFS(g, adjacent);
        }
    }
}
```

**스택을 직접 운영하는 깊이 우선 탐색 코드**

```c
void DFS(int s) {
    int v, w;
    extern struct stack *st;
    extern int visited[];
    InitializeStack(st);
    push(st, s);
    visited[s] = 1;
    while((v = pop(st)) >= 0) {
        visited[v] = 1;
        while(v에 인접한 모든 노드 w) {
            if(!visited[w]) {
                push(st, w);
            }
        }
    }
}
```

두 코드의 차이: 위 코드는 함수가 자기 자신을 다시 호출하는 **순환(재귀) 호출**로 "되돌아가기"를 자동으로 처리하고, 아래 코드는 프로그래머가 직접 **스택 자료구조**를 두고 push/pop으로 "되돌아가기"를 구현한다. 두 방식은 결국 같은 일을 한다 (재귀 호출 자체가 내부적으로 스택을 쓰기 때문).

### 3. 너비 우선 탐색(BFS)

비유: 연못에 돌을 던지면 물결이 동심원을 그리며 퍼져나가듯, 출발점에서 가까운 정점부터 한 겹 한 겹 순서대로 넓게 퍼져나가며 방문하는 방식이다.

**너비 우선 탐색 알고리즘**
1) 시작: 출발점 v를 방문함
2) 다음으로 v에 인접한 정점 w를 모두 방문한 후, 다시 w에 인접한 방문하지 않은 정점들을 차례로 방문함
3) 두 과정을 모든 정점을 한 번씩 방문할 때까지 반복함

너비 우선 탐색은 인접 정점을 모두 방문하기 때문에 스택이 필요하지 않고, 대신 **큐를 사용**한다.

- 출발점이 v1인 경우 BFS 방문 순서: v1, v2, v3, v4, v5, v6, v7, v8
- 출발점이 v4인 경우 BFS 방문 순서: v4, v2, v8, v5, v1, v6, v3, v7

**너비 우선 탐색 코드**

```c
void BFS(Graph* g, int s) {
    int i, adjacent;
    int visited[MAX_VERTICES];
    for(i = 0; i < g -> nv; i++) {
        visited[i] = 0;
    }

    int queue[MAX_VERTICES];
    int front = 0, rear = 0;

    visited[s] = 1;
    queue[rear++] = s;

    while(front != rear) {
        s = queue[front++];
        printf("%d", s);
        for(adjacent = 0; adjacent < g -> nv; adjacent++) {
            if(g -> adj[s][adjacent] && !visited[adjacent]) {
                visited[adjacent] = 1;
                queue[rear++] = adjacent;
            }
        }
    }
}
```

**DFS vs BFS 비교**

| 구분 | 사용하는 자료구조 | 탐색 방식 |
|---|---|---|
| 깊이 우선 탐색(DFS) | 스택 | 자손을 먼저 방문한 후(더 이상 방문할 자손이 없으면) 전 단계 형제를 방문 |
| 너비 우선 탐색(BFS) | 큐 | 모든 형제를 먼저 방문한 후 자손을 방문 |

### 4. 신장 트리(Spanning Tree)

**트리의 정의(복습)**: 트리는 사이클이 없는 단순 그래프다. 트리는 그래프이기는 하지만 루트를 가지기 때문에 (일반 그래프에는 없는) 계층 개념이 있고, 사이클이 없어서 한 정점에서 다른 정점으로 가는 경로가 유일한 구조다.

**신장 트리의 정의**: 신장 트리(spanning tree)란 그래프 G의 모든 정점과 간선의 일부(또는 전부)를 포함하는 트리다.
- 주어진 그래프의 정점을 모두 포함함
- n개의 정점을 갖는 그래프에서 최소 n-1개의 간선으로 구성한 그래프

**G의 최소 부분 그래프**: 그래프 G의 부분 그래프 중에서 간선의 수가 가장 작은 것.

비유: 전국 모든 도시(정점)를 도로(간선)로 연결하되, 어디로 가든 길이 하나만 있고 빙빙 도는 순환로(사이클)가 없도록 "꼭 필요한 도로만" 남긴 것이 신장 트리다.

**신장 트리의 예**: 하나의 그래프 G에서도 어떤 간선을 선택하느냐에 따라 여러 개의 서로 다른 신장 트리가 나올 수 있다 (슬라이드에서 같은 그래프 G로부터 모양이 다른 4개의 신장 트리 예시를 보여줌).

**탐색 신장 트리**: 그래프를 DFS 또는 BFS로 탐색하면서 "실제로 이동에 사용한 간선"만 남기면 그 자체가 하나의 신장 트리가 된다. 이렇게 만든 신장 트리를 각각 **깊이 우선 신장 트리**, **너비 우선 신장 트리**라고 부른다. 같은 그래프라도 DFS로 만든 신장 트리와 BFS로 만든 신장 트리는 모양이 다르다.

### 5. 최소 비용 신장 트리

**정의**: 가중치 그래프 G의 가중치가 작은 간선을 선택하여 구성된 신장 트리를 **최소 비용 신장 트리**라고 한다. (주의: 교재의 최소 비용 신장 트리 알고리즘은 항상 "전역적으로 가장 저렴한" 신장 트리의 구축을 보장하지는 않는다 — 이 과목에서 배우는 프림/크루스컬 알고리즘은 사실 항상 최적해(전체 최소 비용)를 찾아주는 알고리즘이지만, 슬라이드는 "알고리즘을 따라했다고 무조건 최소가 되는 건 아니다"라는 주의를 강조하고 있다.)

예시 가중치 그래프 (정점 1~6, 간선과 비용):

```
{1,2}=10  {1,3}=30  {1,5}=45
{2,4}=25  {2,5}=50
{3,4}=40  {3,6}=15
{4,6}=20
{5,6}=55
```

#### (1) 프림(Prim) 알고리즘

비유: "이미 연결된 우리 동네"에서 가장 싸게 연결할 수 있는 옆 동네를 하나씩 골라서 계속 동네를 넓혀가는 방식이다. 항상 "지금까지 고른 정점들"에 붙어있는 간선 중에서만 고른다.

**정의**: n개의 정점을 갖는 연결 그래프 G에 대한 최소 비용 신장 트리 T를 구하는 알고리즘.
- 그래프 전체에서 최소 비용을 갖는 간선 {u, v}를 선택하여 이 간선을 최소 비용 신장 트리 T에 추가함
- 정점 u 또는 v에 연결된(인접한) 간선 중에서 최소 비용을 갖는 간선 {u, w} 또는 {v, w}를 선택함. 만일 이 간선을 최소 비용 신장 트리 T에 추가하였을 때 사이클을 형성하지 않으면 T에 추가하고, 아니면 무시함
- 같은 방법으로, 최소 비용 신장 트리 T가 n-1의 간선을 갖거나 간선이 모두 처리될 때까지 반복함

**프림 알고리즘 의사코드**

```c
void prim() {
    T = ∅;
    W = ∅;
    E 로부터 최소 비용인 간선 {v, w}를 선택;
    while(T 는 n-1개 이하의 간선 포함 && E 는 공집합 아님) {
        E 에서 간선 {v, w}를 제거;
        if({v, w}가 T 내에서 사이클을 생성 안함) {
            T = T ∪ {{v, w}};  // 선택한 간선 추가
            W = W ∪ {v, w};    // 선택한 정점 추가
        }
        else 간선 {v, w}를 버림;
        E 로부터 W 내의 정점과 최소 비용으로 연결된 간선 {v, w}를 선택;
    }
}
```

**프림 알고리즘 진행 과정 예시** (위 가중치 그래프 기준)

| 간선 | 비용 | 정점집합 W |
|---|---|---|
| {1,2} | 10 | {1,2} |
| {2,6} | 25 | {1,2,6} |
| {3,6} | 15 | {1,2,3,6} |
| {6,4} | 20 | {1,2,3,4,6} |
| {1,4} | 30 | 사이클 생성 → 추가하지 않음 |
| {3,5} | 35 | {1,2,3,4,5,6} |

→ 최종 선택된 간선: {1,2}, {2,6}, {3,6}, {6,4}, {3,5} (총 5개 = n-1, n=6)

#### (2) 크루스컬(Kruskal) 알고리즘

비유: 프림이 "동네를 넓혀가는" 방식이라면, 크루스컬은 "전국에서 제일 싼 도로부터 순서대로 하나씩 깔되, 이미 깔린 도로끼리 빙 돌아가는 모양(사이클)만 되지 않으면 계속 깐다"는 방식이다. 중간 과정에서는 아직 서로 연결되지 않은 여러 개의 작은 나무(숲)들이 있을 수 있다.

**정의**
- 그래프 전체에서 최소 비용을 갖는 간선 {u, v}를 선택하여 이 간선을 최소 비용 신장 트리 T에 추가함
- 남은 간선 중에서 무조건 최소 비용인 간선을 선택한 후, 사이클을 형성하지 않으면 그 간선을 선택함
- 중간 과정에 있는 T는 하나의 트리가 아니고 여러 개의 분리된 트리, 즉 숲일 수 있음
- 같은 방법으로, 최소 비용 신장 트리 T가 n-1의 간선을 갖거나 간선이 모두 처리될 때까지 반복

**크루스컬 알고리즘 의사코드**

```c
void kruskal() {
    while(T 가 n-1개 이하의 간선을 포함 && E 가 공집합 아님) {
        E 로부터 최소 비용인 간선 {v, w}를 선택;
        E 에서 간선 {v, w}를 제거;
        if({v, w}가 T 내에서 사이클을 생성 하지 않음)
            T = T ∪ {{v, w}};
        else
            간선 {v, w}를 버림;
    }
}
```

**크루스컬 알고리즘 진행 과정 예시** (같은 그래프, 비용이 작은 순서로만 판단)

| 간선 | 비용 | 비고 |
|---|---|---|
| {1,2} | 10 | 선택 |
| {3,6} | 15 | 선택 |
| {4,6} | 20 | 선택 |
| {2,6} | 25 | 선택 |
| {1,4} | 30 | 사이클 생성 → 추가하지 않음 |
| {3,5} | 35 | 선택 |

→ 최종 선택된 간선: {1,2}, {3,6}, {4,6}, {2,6}, {3,5} (총 5개 = n-1)

**프림 vs 크루스컬 비교**: 프림은 매 단계마다 "이미 고른 정점 집합 W"에 인접한 간선들 중에서만 최소 비용을 고르지만, 크루스컬은 정점 집합과 상관없이 "그래프 전체 간선 중" 무조건 최소 비용인 간선을 고르고 사이클 여부만 확인한다. 둘 다 결과적으로 똑같은 최소 비용 신장 트리를 찾아낼 수 있다(이 예시에서는 두 알고리즘이 고른 간선 집합이 동일함 — {1,2},{3,6},{4,6},{2,6},{3,5}).

#### (3) 솔린(Sollin) 알고리즘

비유: 프림(나무 하나를 키우기)과 크루스컬(간선을 하나씩 줍기) 사이의 중간 방식으로, 여러 그루의 어린 나무(숲)를 동시에 키우다가 서로 합쳐나가는 방식이다.

**정의**
- 간선이 하나도 없는 그래프의 모든 정점들로 구성된 숲에서 시작함
- 단계가 거듭되면서 숲 내의 트리들이 최소 비용을 갖는 간선으로 연결됨 (각 트리마다 "나를 다른 트리와 연결하는 가장 싼 간선"을 동시에 고름)

**솔린 알고리즘 의사코드**

```c
void sollin() {
    // 집합 E 의 초기 상태는 주어진 그래프의 간선 집합
    // 집합 F 의 초기 상태는 그래프의 모든 정점들로 구성된 간선이 없는 숲
    T = ∅;
    while(T 는 완전한 하나의 트리가 아님 && E 는 공집합이 아님) {
        for(F 내의 각각의 트리 T 에 대하여) {
            T 와 다른 트리를 연결하는 E 의 간선 {v, w} 중에서 최소비용 간선 {v, w} 선택;
            T = T ∪ {{v, w}};
            E 에서 간선 {v, w}를 제거;
        }
        T 에 새로 추가된 간선을 포함하여 F 를 수정;
    }
}
```

**솔린 알고리즘 진행 과정 예시** (같은 그래프 기준)
- 1단계: 각 트리(정점)가 동시에 가장 싼 이웃 간선을 고름 → {1,2}, {3,6}, {4,6}, {5,3} 이 한꺼번에 선택되어 숲이 두 덩어리로 합쳐짐
- 2단계: 남은 두 덩어리를 연결하는 간선 중 최소 비용인 {2,6}(비용 25)을 선택하여 하나의 완전한 신장 트리 완성

→ 최종 선택된 간선: {1,2}, {3,6}, {4,6}, {5,3}, {2,6} (총 5개 = n-1)

### 6. (14강 복습) 독립 정점과 널 그래프

- **독립 정점**: 다른 어떤 정점과도 인접하지 않은 정점
- **널(null) 그래프**: 독립 정점만으로 구성한 그래프이며, 간선의 집합 E는 공집합이다. 즉 정점만 있는 그래프(간선이 존재하지 않는 그래프).

### 정리하기 (슬라이드 요약)

- 그래프 탐색: 그래프 내 특정 정점을 찾는 연산으로, 트리와 다르게 루트 노드가 없으므로 특정 정점에서 시작함
- 그래프 순회: 특정 정점에서 시작하여 그래프의 모든 정점을 빠짐없이 그리고 중복없이 방문하는 것
- 깊이 우선 탐색: 그래프 순회 알고리즘의 하나로 특정 정점에서 시작하여 자손을 먼저 방문한 후(더 이상 방문할 자손이 없으면) 전 단계 형제를 방문함
- 너비 우선 탐색: 특정 정점에서 시작하여 모든 형제를 방문한 후 자손을 방문함
- 최소 비용 신장 트리: 그래프의 모든 정점을 포함하는 사이클이 없는 부분 그래프, 즉 트리를 신장 트리라 함. 가중 그래프에서 비용이 최소인 신장 트리를 최소 비용 신장 트리라고 함

## 기억해야 할 키워드

- **그래프 탐색**: 그래프에서 특정 정점을 찾는 연산. 루트가 없으므로 임의의 정점에서 시작
- **깊이 우선 탐색(DFS, Depth First Search)**: 한 방향으로 갈 수 있는 만큼 깊이 들어간 뒤 되돌아오는 탐색, 스택 사용
- **너비 우선 탐색(BFS, Breadth First Search)**: 가까운 정점부터 한 겹씩 퍼져나가는 탐색, 큐 사용
- **신장 트리(spanning tree)**: 그래프 G의 모든 정점과 간선의 일부(또는 전부)를 포함하는 트리. n개 정점이면 최소 n-1개 간선
- **탐색 신장 트리**: DFS/BFS 과정에서 실제로 사용한 간선만으로 만들어지는 신장 트리 (깊이 우선 신장 트리 / 너비 우선 신장 트리)
- **최소 비용 신장 트리**: 가중치 그래프에서 비용의 합이 가장 작은 신장 트리
- **프림(Prim) 알고리즘**: 이미 선택한 정점 집합에 인접한 간선 중 최소 비용 간선을 계속 선택하여(사이클 제외) 신장 트리를 키워가는 방식
- **크루스컬(Kruskal) 알고리즘**: 정점 집합과 무관하게 전체 간선 중 무조건 최소 비용 간선을 선택(사이클만 제외)하는 방식. 중간 과정은 여러 개의 숲일 수 있음
- **솔린(Sollin) 알고리즘**: 간선 없는 숲에서 시작해 각 트리가 동시에 최솟값 간선으로 다른 트리와 연결되며 합쳐지는 방식
- **사이클(cycle)**: 한 정점에서 출발해 같은 정점으로 되돌아오는 경로. 신장 트리/최소 비용 신장 트리는 사이클을 생성하지 않아야 함
- **독립 정점**: 다른 어떤 정점과도 인접하지 않은 정점
- **널(null) 그래프**: 독립 정점만으로 구성되어 간선 집합이 공집합인 그래프
