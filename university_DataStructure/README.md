# university_DataStructure — 방송통신대 자료구조 튜터

이 폴더는 **방송통신대학교 [자료구조] 과목** 학습을 위한 개인 튜터 시스템입니다.
루트의 Python 개인 튜터(`CLAUDE.md`)와는 별개의 과목/진행 상황을 관리합니다.

## 목적

- 방송통신대 자료구조 강의 진도를 기록하고, 배운 개념을 정리
- 이전에 배운 개념 + 새로 배운 개념을 랜덤으로 섞어 반복 학습
- 오답을 누적 기록하고, 자주 틀리는 부분은 개념 재학습으로 연결
- 최종 목표: 자료구조 개념을 완벽히 이해하고 **학점 만점**

## 폴더 구조

```
university_DataStructure/
├── README.md              # 이 파일 (설명)
├── 학습프롬프트.md          # 튜터가 항상 따라야 하는 학습 규칙 (시스템 프롬프트 역할)
├── learn/                  # 강의별 개념 정리
│   └── N강_학습제목(개념).md   # 예: 01강_배열과 리스트(개념).md
└── tutor/                  # 문제 풀이 및 오답 기록
    └── 날짜_오답.md          # 예: 2026-08-31_오답.md
```

## 사용 흐름

1. 사용자가 "몇 강 배웠다 / 오늘 수업 내용은 이렇다"고 알려주면
   → `learn/` 에 새 강의 개념 정리 파일 생성
2. 개념 정리 후, 이전 강의 + 새 강의 내용을 섞어서 객관식/주관식/서술형 문제 출제
3. 채점은 실제로 풀이/코드를 검증한 뒤 진행하고, 오답은 `tutor/날짜_오답.md`에 기록
4. 반복적으로 틀리는 개념은 `learn/`의 해당 강의 파일로 돌아가 재학습 후 다시 응용 문제 출제
5. 매 세션 종료 시 GitHub에 commit/push 하여 학습 기록을 보존

자세한 튜터 행동 규칙은 [`학습프롬프트.md`](./학습프롬프트.md) 를 참고하세요.
