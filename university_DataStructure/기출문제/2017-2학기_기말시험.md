## 59. 다음은 큐를 이용한 너비 우선 탐색(BFS) 알고리즘의 의사코드이다. 아래의 코드에서 빈 칸 ㉠, ㉡에 들어갈 알맞은 코드는 무엇인가? (2점)
```c
① void BFS(int v) {
②   int w;
③   extern struct queue *q;
④   VISITED[v] = 1;
⑤   InitializeQueue(q);
⑥   AddQueue(q,v)
⑦   while( ㉠ ){
⑧       v=DeleteQueue(q);
⑨       while( ㉡ ){
⑩           if(!VISITED[w]){
⑪               AddQueue(q,w);
⑫               VISITED[w]=1;
⑬           }
⑭       }
⑮   }
⑯ }
```
① ㉠: v에 인접한 모든 노드 w / ㉡: !q_empty()
② ㉠: !q_empty() / ㉡: v에 인접한 모든 노드 w
③ ㉠: q_empty() / ㉡: v에 인접한 모든 노드 w
④ ㉠: !VISITED[w] / ㉡: v에 인접한 모든 노드 w
