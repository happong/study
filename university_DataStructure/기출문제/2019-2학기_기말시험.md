## 40. 다음은 연결 리스트 프로그램의 일부이다. 현재 헤드 노드만 존재하며, x값은 100이라고 가정하고, NewNode의 주소값은 5000이라고 가정할 때, 결과 상태를 그림으로 표현한 것으로 알맞은 것은 무엇인가? (2점)
```c
void addNode(linkedList_h* H, int x) {
    listNode* NewNode;
    listNode* LastNode;
    NewNode = (listNode*)malloc(sizeof(listNode));
    NewNode->data = x;
    NewNode->link = NULL;

    if (H->head == NULL) {
        H->head = NewNode;
        return;
    }
    LastNode = H->head;
    while(LastNode->link != NULL)
        LastNode = LastNode->link;
    LastNode->link = NewNode;
}
```
(보기: head가 NewNode(주소 5000, data=100, link=null)를 직접 가리키는 그림 등 4개 — 원본 PDF 참고. 현재 헤드 노드만 있고 비어있으므로 head->head==NULL 분기를 타는 것이 핵심)
