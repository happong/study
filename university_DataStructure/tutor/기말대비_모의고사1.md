# 기말대비 모의고사 1 (1~15강 종합, 20문제)

출제 범위: 1~15강 전체. 문제 유형: 객관식/계산/트레이스/서술형 혼합.
**풀기 전에는 정답을 보지 마세요** — 정답은 파일 맨 아래에 있습니다.

---

**[1강·초급·객관식]** 알고리즘이 반드시 만족해야 하는 5가지 조건에 속하지 **않는** 것은?
① 출력 ② 명확성 ③ 효율성 ④ 유한성

**[2강·중급·계산]** 7행 10열 행렬에 0이 아닌 원소가 12개 있다면, 효율적 배열표현 표는 몇 행 몇 열인가? (계산 과정 포함)

**[3강·중급·변환]** 중위 표기식 `(A+B)*(C-D)/E` 를 후위 표기식으로 변환하시오. (단계별 과정 포함)

**[4강·초급·객관식]** 원형 큐에 대한 설명으로 옳은 것은?
① front 값만으로 큐의 포화 상태를 판단할 수 있다
② 나머지 연산자(%)를 이용해 배열 끝에서 처음으로 되돌아가게 한다
③ 메모리 공간을 항상 100% 활용할 수 있다
④ rear와 front가 같으면 항상 포화 상태를 의미한다

**[5강·중급·서술형]** 연결 리스트에서 새 노드를 삽입할 때, "새 노드의 링크를 먼저 설정"하고 그 다음 "선행 노드의 링크를 설정"하는 순서를 지켜야 하는 이유를 설명하시오.

**[6강·초급·객관식]** 원형 연결 리스트와 이중 연결 리스트에 대한 설명으로 **틀린** 것은?
① 원형 연결 리스트는 마지막 노드가 다시 첫 번째 노드를 가리킨다
② 이중 연결 리스트는 각 노드가 선행 노드와 후행 노드를 모두 가리키는 링크를 갖는다
③ 원형 연결 리스트는 선행 노드를 찾는 문제를 완전히 해결한다
④ 이중 연결 리스트는 단순 연결 리스트보다 메모리를 더 사용한다

**[7강·중급·트레이스]** 다음 이진트리의 중위 순회와 후위 순회 결과를 각각 쓰시오.
```
        M
       / \
      K   S
     /   / \
    F   R   T
```

**[8강·중급·계산]** 노드가 11개인 이진 트리에서, 빈 포인터(NULL 포인터)는 몇 개인가?

**[9강·고급·트레이스]** 다음 최소 힙에 숫자 3을 삽입할 때, 최종적으로 3이 어느 자리에 위치하게 되는지 과정과 함께 설명하시오.
```
        4
      /   \
     7     9
    / \
   12  15
```

**[10강·중급·계산]** 노드가 4개일 때, 서로 다른 모양의 이진 트리는 몇 가지인가? (카탈랑 수 공식과 계산 과정 포함)

**[11강·초급·객관식]** AVL 트리와 BB 트리에 대한 설명으로 **틀린** 것은?
① AVL 트리는 좌우 서브트리의 높이 차이가 최대 1까지 허용된다
② BB 트리는 좌우 서브트리의 무게(잎 개수) 비율로 균형을 판단한다
③ AVL 트리와 BB 트리 모두 삽입/삭제 후 재조정에 O(n)개의 노드 이동이 필요하다
④ 두 트리 모두 완전한 균형보다는 "거의 균형"을 허용하는 방식이다

**[11강·고급·서술형]** Splay 트리에서 "Zig-Zig" 회전과 "Zig-Zag" 회전은 각각 어떤 경우에 적용되는지 설명하시오.

**[12강·중급·객관식]** 차수가 5인 B 트리에서, 루트와 잎을 제외한 각 노드가 가져야 하는 최소 서브트리 개수는?

**[12강·고급·서술형]** B+ 트리가 B 트리와 다른 점을 "데이터 저장 위치"와 "잎 노드 간 연결" 두 가지 관점에서 설명하시오.

**[13강·초급·객관식]** 레드 블랙 트리에서 "레드 간선"이 의미하는 것은?
① 서로 다른 2-3-4 노드 사이의 부모-자식 관계
② 같은 2-3-4 노드 안에 있던 키들 사이의 관계
③ B+ 트리의 순차 포인터 연결
④ AVL 트리의 높이 불균형 지점

**[14강·초급·계산]** 정점이 6개인 완전 무방향 그래프의 간선 개수는?

**[14강·중급·객관식]** 그래프를 인접 리스트로 표현할 때의 설명으로 옳은 것은?
① 두 정점의 연결 여부를 항상 O(1)에 확인할 수 있다
② 정점 수가 많고 간선이 적은 희소 그래프에서 인접 행렬보다 메모리가 효율적이다
③ n×n 크기의 2차원 배열을 사용한다
④ 무방향 그래프는 인접 리스트로 표현할 수 없다

**[15강·중급·트레이스]** 다음 그래프에서 정점 1부터 시작해 BFS를 수행한 방문 순서를 쓰시오. (인접 정점은 번호가 작은 순서로 방문)
> 간선: 1-2, 1-3, 2-4, 3-4, 3-5, 4-5

**[15강·초급·객관식]** 최소 비용 신장 트리를 구하는 알고리즘 중, "이미 선택된 정점 집합에 인접한 간선 중에서만" 최소 비용 간선을 고르는 것은?
① 크루스컬 ② 프림 ③ 솔린 ④ DFS

**[종합·고급·서술형]** 이진 탐색 트리(BST)에서 자식이 2개인 노드를 삭제할 때의 처리 방법을 설명하고, 이 방법이 왜 "재귀적인 과정"이라고 할 수 있는지 서술하시오.

6. ③ (원형 연결 리스트는 순환 구조만 제공할 뿐 선행 노드 탐색 문제는 해결 못함 — 그건 이중 연결 리스트의 역할)
7. 중위: F, K, M, R, S, T / 후위: F, K, R, T, S, M

15. ②

18. 1, 2, 3, 4, 5
19. ②
20. 왼쪽 서브트리의 최댓값(선행자) 또는 오른쪽 서브트리의 최솟값(후속자)을 찾아 삭제할 노드의 값을 그 값으로 대체한 뒤, 실제 삭제 대상은 그 선행자/후속자 노드로 바뀐다. 이 선행자/후속자 노드는 자식이 0개 또는 1개이므로, 결국 더 단순한 삭제 경우로 넘어가 처리된다 — 이 과정이 "2개 자식 삭제 → 더 단순한 경우로 치환"되는 흐름이라 재귀적이라고 한다.
