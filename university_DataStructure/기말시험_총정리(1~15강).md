# 자료구조 기말시험 총정리 (1강~15강)

방송통신대 자료구조(정광식 교수) 1~15강 전체 핵심 개념 압축 정리.
각 항목은 `learn/` 폴더의 해당 강의 파일에 훨씬 자세히 정리되어 있으니, 헷갈리는 부분은 원본 강의 파일을 참고할 것.

---

## A. 자료구조 기초 (1강)

- **자료(Data)**: 현실에서 관찰·측정으로 얻은 값/사실. **정보(Information)**: 자료를 처리(가공)해서 얻은, 의사결정에 쓸 수 있는 결과물. 공식: **I = P(D)**
- **추상화(Abstraction)**: 공통적인 개념을 이용하여 같은 종류의 다양한 객체를 정의하는 것
- **자료구조(Data Structure)**: 추상화를 통해 알고리즘에서 사용할 자료의 논리적 관계를 구조화한 것
- **추상 자료형(ADT, Abstract Data Type)**: 자료값의 집합 + 연산의 집합으로 자료의 논리적 성격을 정의한 형식. 실제 구현 방법은 포함하지 않음
- **알고리즘의 5가지 조건**: 출력, 유효성, 입력, 명확성, 유한성
- **시간 복잡도**: O(n)으로 표현. **공간 복잡도**: Sp = Sc(고정) + Se(가변)
- **자료구조 분류**: 미리 정의된 자료구조(정수·배열·구조체·포인터) vs 개발자 정의 자료구조(리스트·스택·큐·트리·그래프)

## B. 선형 자료구조 (2~6강)

### 배열 (2강)
- 배열 = `<index, value>` 쌍의 집합. ADT 연산: `create(n)`, `retrieve(a,i)`, `store(a,i,e)`
- 1차원 배열 주소 공식: **A[i] 주소 = α + i×k** (α: 시작주소, k: 원소크기)
- 2차원 배열: **행 우선(Row-major, C언어)** vs **열 우선(Column-major)** 저장
- **희소행렬**: 0이 아닌 값이 훨씬 많은 일반 행렬과 반대. 효율적 표현 = (행,열,값) 3열 저장. **표 전체 행 수 = 0아닌 원소 개수+1(헤더), 열 수 = 항상 3**

### 스택 (3강)
- LIFO(후입선출). `top` 변수로 관리, `top==-1`이면 공백. 연산: push, pop, StackIsFull, StackIsEmpty
- 응용: 시스템 스택, 함수 호출 관리, 수식 계산, 인터럽트 처리, DFS
- **중위→후위 변환**: ①우선순위대로 괄호 묶기 → ②각 묶음에서 연산자를 가장 오른쪽으로 이동(안쪽부터) → ③괄호 제거
- **후위식 계산(evalPostfix)**: 숫자는 push, 연산자 만나면 `oper2=pop(), oper1=pop()` 후 `oper1 연산자 oper2` 계산해서 push

### 큐 (4강)
- FIFO(선입선출)/FCFS. `front`(삭제), `rear`(삽입) 변수로 관리
- 배열 큐의 문제점: front/rear가 계속 오른쪽으로만 이동 → 거짓 포화 상태 발생
- **원형 큐**: 나머지 연산자(%)로 배열을 순환 구조로 만들어 해결. 보통 한 칸을 비워두는 방식으로 포화/공백 구분
- 응용: FCFS 스케줄링, Round Robin 스케줄링, BFS

### 연결 리스트 (5~6강)
- 노드(data+link)로 구성, `head` 포인터가 첫 노드, 마지막 링크는 NULL
- 삽입/삭제 시 **반드시 순서를 지켜 링크 연결**(먼저 새 노드가 후행 노드를 가리키게, 그다음 선행 노드가 새 노드를 가리키게) — 순서를 바꾸면 리스트 유실
- **단순 연결 리스트**의 한계: 선행 노드를 찾으려면 head부터 재검색해야 함
- **원형 연결 리스트**: 마지막 노드가 다시 head를 가리킴. 라운드 로빈에 적합하나 무한루프 위험
- **이중 연결 리스트**: 노드마다 Llink(선행)+Rlink(후행) 2개 링크. 양방향 이동·빠른 삭제 가능하나 메모리 더 사용

## C. 트리 기초 (7~10강)

### 이진 트리 (7강)
- 모든 노드의 차수가 2 이하. **포화/완전 이진 트리**: 완전 이진 트리 = 마지막 레벨 제외 모두 채워지고 마지막 레벨은 왼쪽부터 채움
- **순회**: 전위(PLR, Preorder) = 루트→왼쪽→오른쪽 / 중위(LPR, Inorder) = 왼쪽→루트→오른쪽 / 후위(LRP, Postorder) = 왼쪽→오른쪽→루트
- 일반 트리→이진 트리 변환: **첫째 자식=왼쪽 자식, 다음 형제=오른쪽 자식**

### 스레드 이진 트리 (8강)
- 스택/재귀 없이 순회하기 위해 빈 포인터(NULL)를 "스레드"로 재활용
- 오른쪽 스레드 = 후속 노드, 왼쪽 스레드 = 선행 노드
- 노드 n개인 이진 트리의 **NULL 포인터 개수 = n+1**
- threadFlag로 "진짜 자식"인지 "스레드"인지 구분 필요 (삽입/삭제 시 필수)

### 힙 (9강)
- **우선순위 큐**를 구현하는 **완전 이진 트리**. 부모-자식 간에만 대소관계 있음(형제간은 없음)
- **최소 힙**: 루트=최솟값, 부모<자식 / **최대 힙**: 루트=최댓값, 부모>자식
- 배열 인덱스 공식(1번부터): 부모 i → 왼쪽자식 2i, 오른쪽자식 2i+1
- **삭제**: 루트 꺼내고 마지막 노드를 임시 루트로 올린 뒤 더 작은 자식과 비교하며 내려감(sift-down)
- **삽입**: 맨 끝에 놓고 부모와 비교하며 올라감(sift-up)

### 선택 트리 / 숲 / 이진 트리 개수 (10강)
- **승자 트리**: 두 자식 중 작은 값(승자)이 부모로. 루트=최솟값
- **패자 트리**: 패자를 부모에 저장, 승자는 더 위로. 별도 0번 노드에 최종 승자 저장. 메모리 지역성이 승자 트리보다 좋음
- **숲**: n(≥0)개의 분리된 트리 집합
- 노드 n개인 서로 다른 이진 트리 개수 = **카탈랑 수** (2n)!/(n!(n+1)!)
- **전위+중위 순회**를 함께 알면 트리 모양을 유일하게 복원 가능 (전위+후위만으로는 불가)

## D. 탐색 트리 계열 (11~13강)

### BS/Splay/AVL/BB (11강)
- **이진 탐색 트리(BST)**: 왼쪽 서브트리<자신<오른쪽 서브트리. 중위 순회하면 정렬된 순서로 출력
- 삭제: 자식 0개(그냥 제거), 1개(자식이 부모에 직결), 2개(선행자=왼쪽 서브트리 최댓값 or 후속자=오른쪽 서브트리 최솟값으로 대체 후 재귀 삭제)
- **Splay 트리**: 최근 접근 노드를 루트로 끌어올림. Zig(단일회전)/Zig-Zig(같은 방향 2회전)/Zig-Zag(지그재그 이중회전)
- **AVL 트리**: 모든 노드에서 좌우 서브트리 **높이 차 ≤ 1** (높이 균형 트리)
- **BB 트리**: 좌우 서브트리 **무게(잎 개수)** 비율을 균형인수 β(0<β≤1/2)로 제한 (무게 균형 트리)
- 완전 균형 유지는 O(n) 노드 이동 필요하지만 AVL/BB는 **O(log n)**만 필요

### m원 탐색 트리 / B 트리 계열 (12강)
- **m원 탐색 트리**: 노드가 최대 m개 자식. 노드 구조 `P₀k₀P₁k₁...Pₙ` (n≤m-1)
- **B 트리(차수 m)**: ①루트·잎 제외 각 노드 최소 ⌈m/2⌉개 서브트리 ②루트 최소 2개 서브트리 ③모든 잎 노드가 같은 레벨
- 삽입 시 노드가 꽉 차면 **분리(split)**: 중간값을 부모로 올림(연쇄 가능)
- 삭제 시 키 부족하면 형제와 **회전**(여유 있으면) 또는 **결합**(둘 다 최소면)
- **B\* 트리**: 노드를 2/3 이상 채움. 분리 전에 형제로 키 재배치해서 분리 횟수 줄임
- **B+ 트리**: 실제 데이터 주소는 **잎 노드에만**, 잎끼리 순차 포인터로 연결 → 직접 탐색+순차 처리 모두 가능. 인덱스된 순차 파일에 사용

### 2-3 / 2-3-4 / 레드 블랙 트리 (13강)
- **2-3 트리**: 내부 노드가 2-노드(키1,자식2) 또는 3-노드(키2,자식3)만. 모든 잎이 같은 레벨
- 삽입으로 4-노드(오버플로) 되면 가운데 키를 부모로 올리며 분리
- 삭제: 내부 노드는 선행자/후속자로 대체 후 삭제, 잎이 비면 회전(형제가 3-노드) 또는 결합(형제가 2-노드)
- **2-3-4 트리**: 4-노드(키3,자식4)까지 허용 → 재구성 빈도 낮아 더 효율적. **사전 분리(top-down split)** 기법 사용
- **레드 블랙 트리**: 2-3-4 트리를 이진 트리 모양으로 표현. 같은 노드 내 관계=**레드 간선**, 서로 다른 노드 간 부모-자식=**블랙 간선**. 탐색은 일반 BST와 동일

## E. 그래프 (14~15강)

### 그래프 기본 (14강)
- **G = (V, E)**: 정점집합 V, 간선집합 E
- 무방향 그래프 간선: `{v1,v2}` (실선) / 방향 그래프 간선: `(v1,v2)` (화살표)
- **다중 그래프**: 두 정점 사이 간선 여러 개 / **가중 그래프**: 간선에 가중치
- 완전 무방향 그래프 간선 수 = **ₙC₂ = n(n-1)/2**, 방향 그래프 최대 간선 수 = **ₙP₂ = n(n-1)**
- **차수**: 무방향=연결된 간선 수. 방향=진입차수+진출차수
- **경로/단순경로(정점 중복 없음)/기본경로(간선 중복 없음)/사이클(시작=끝인 단순경로)**
- **루프**: 자기 자신으로 연결되는 간선(길이 1 경로)
- **무사이클 그래프 = 트리**. 방향 있는 무사이클 그래프 = **DAG**
- **독립 정점**: 어떤 정점과도 인접 안 함 / **널 그래프**: 독립 정점만, E=공집합
- **표현법**: 인접 행렬(n×n, 빠른 연결확인/메모리낭비) vs 인접 리스트(정점별 연결리스트, 메모리 효율적/탐색은 느릴 수 있음)

### 그래프 탐색 / 신장 트리 (15강)
- **DFS(깊이 우선 탐색)**: 스택 사용(순환호출도 내부적으로 스택). 한 방향으로 깊이 들어갔다 막히면 되돌아옴
- **BFS(너비 우선 탐색)**: 큐 사용. 가까운 정점부터 한 겹씩 퍼짐
- **신장 트리**: 그래프의 모든 정점 포함, n개 정점이면 **n-1개 간선**
- **최소 비용 신장 트리 알고리즘 3가지**:
  - **프림(Prim)**: 이미 고른 정점집합 W에 인접한 간선 중 최소비용 선택(사이클 제외) — "동네를 넓혀감"
  - **크루스컬(Kruskal)**: 정점집합 무관, 전체 간선 중 무조건 최소비용 선택(사이클만 제외) — 중간에 여러 숲 가능
  - **솔린(Sollin)**: 숲의 각 나무가 동시에 가장 싼 간선으로 다른 나무와 연결되며 합쳐짐

## 전체 트리 분류도 (13~14강에 등장, 암기 추천)

```
                        트리
            /                        \
        이진 트리                  멀티웨이 트리
       /          \                      |
    Heap      이진 탐색 트리        m원 탐색 트리
             /    |      \                |
          AVL   BB    Splay            B-트리
                                     /   |   \
                                   B⁺  B*  2-3 트리
                                  트리 트리     |
                                          2-3-4 트리
                                               |
                                          레드 블랙 트리
```
(스레드 이진 트리, 선택 트리(승자/패자)는 위 분류도와 별개로 "이진 트리의 특수 활용"으로 취급)

## 시험에 자주 나오는 비교/헷갈리는 포인트 모음

| 비교 대상 | 핵심 차이 |
|---|---|
| 스택 vs 큐 | LIFO(한쪽 끝) vs FIFO(양쪽 끝: rear 삽입/front 삭제) |
| 전위·중위·후위 | 루트 방문 "순서"만 다름 (PLR/LPR/LRP) |
| 승자 트리 vs 패자 트리 | 부모에 승자 저장(직관적, 비효율) vs 패자 저장+0번 노드에 승자(메모리 지역성 좋음) |
| AVL vs BB | 높이 균형(서브트리 높이차≤1) vs 무게 균형(잎 개수 비율) |
| B트리 vs B+트리 | 모든 노드에 데이터 vs 잎 노드에만 데이터(+순차 포인터) |
| 2-3-4트리 vs 레드블랙트리 | 한 노드에 키 여러 개 vs 그걸 이진 트리 모양+색깔 간선으로 표현 |
| 프림 vs 크루스컬 | 정점집합 기준으로 확장 vs 전체 간선 기준으로 선택 |
| 인접행렬 vs 인접리스트 | 빠른 연결확인/메모리 많이 씀 vs 메모리 절약/탐색 느릴 수 있음 |
| 진입차수/진출차수 | 방향그래프 전용 개념 (무방향은 그냥 "차수") |
